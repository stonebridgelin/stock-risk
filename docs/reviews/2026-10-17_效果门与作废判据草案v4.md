## 1. 项目目标（"效果"指什么）

1. **及时预警**：
   - **H1**：检查 F\_ref 当日日末是否在警，违反次数必须为零。
     - 乙类未知（检查点存在、方法状态无法确定，以及其他一切未知）计为违反。
     - 甲类未知（检查点因价格数据本身无法建立）不计入违反，但甲类比例超过登记的上限时，该期间记为"证据不足"。
     - 另报敏感性结果（甲类全部按违反计），只作描述。
   - **S1**：衡量**延续至谷底之前的持续预警段的起点**得分。它不是首条通知的延迟。
   - 另报：首次实际 START 的日期与当时的已实现跌幅，以及首次提醒之后脱警的日数。
2. **及时解除**：
   - **及时性**：S2、s、h\_tail，以及解除相对恢复参考点的时间。
   - **解除质量**：解除后的不利变化率 p、p\_L；谷底前的错误解除次数。
   - 两类必须并列报告。不利率低而解除迟迟不来，不算效果好。
3. **通知负担**：
   - 占用率；
   - F，即 START 与 ESCALATE 的频次；
   - 实际投递的消息量，单列。
4. **只陈述证据**，不给买卖建议。

## 2. 检查点

每个检查点的结果分为四种，分别记录：
- **通过**；
- **证据不足或无法判断**：附原因；
- **未达标**；
- **统计方法不适用**。

除"通过"以外，三种都不能上线，也都不能当作通过。但"证据不足"与"统计方法不适用"不等于已证明算法无效。

**判定口径**（G-EF-03）：
- 各指标是否可判定，以及 17 号已登记的例外，严格按 17 号与已裁定的规则执行。例如 h\_tail 任一波动组主口径合格窗口不足 20 时，只按整体判定（17 号第 3.1 节，E4-01），这种情况照常判定，不算"证据不足"。
- 只有协议要求必须判定的范围（全体，或协议要求的分组）处于 17 号第 10A 节的"证据不足"时，才记为"证据不足或无法判断"。
- 只有重采样检验的有效重复不足（B\_v < 0.99B，E5-01）时，才记为"统计方法不适用"。
