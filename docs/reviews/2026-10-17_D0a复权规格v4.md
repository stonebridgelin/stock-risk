## 1. 规范计算坐标：以锚日为准的前向复权 F

### 1.1 定义

记锚日为 a。第 k 次行动的除权日为 e\_k，向后因子为 b\_k（第 4、5 节）。

- 累计因子：B\_i = ∏ { b\_k ：a < e\_k ≤ i }
- **前向复权价**：F\_i = R\_i ÷ B\_i，其中 R\_i 为原始价（开、高、低、收同样处理）
- **前向复权成交量**：F\_V,i = V\_i × ∏ { b\_k ：a < e\_k ≤ i，k 为拆股 }，分红不进入成交量

### 1.2 合规性来自构造

F\_i 只用除权日不晚于 i 的行动。所以第 t 日的信号用到的任何 F\_i（i ≤ t），都只依赖截至 t 已生效的行动，满足红线 2 的"复权不能借用未来"。行动的可得性另按第 3 节核验。

### 1.3 规范坐标

- **研究与生产都用 F** 计算信号、F\_ref 与评价。
- 项目的数值协议（6 位量化、价格容差 ε\_p、并列取值规则）**在 F 坐标下定义**。F 就是"系统看到的价格"，F 之上的计算结果就是系统的结果。
- **生产口径因此改变**：11 号原定生产按供应商当日的 BR 计算。改为生产也由原始价与公司行动，按本规格自行计算 F。供应商 BR 只用于核对，不用于计算。这是对 11 号的修订，记入第 13 节；生产尚未实施，不影响现有代码。
- **绝对价格条件**（"价格低于 5 美元"、成交额）一律用原始价与原始成交量（17 号第 1.1 节）。

### 1.4 与"截至 T 的复权视图"的关系（只作说明，不作验收依据）

在因子为正、有限、按同一规则处理、并且用精确算术时：

> S\_i(T) = R\_i × B\_T ÷ B\_i = F\_i × B\_T

即决策日 T 的复权视图只是 F 乘以一个常数。所以 F 上的比例不变量（回撤、比率、大小比较）与 S(T) 上的相同。

有限精度下，量化与固定容差不满足严格的比例不变，F 与 S(T) 的离散结果可能在边界上不同，而且一次并列变化可能影响之后整段状态。因为系统规定以 F 为准，这种差异不是缺陷，**不需要接受标准**；第 10 节第 4 项只把它作为诊断来报告。

### 1.5 为什么不选其他做法

| 做法 | 问题 |
| --- | --- |
| 以 2019-12-31 为锚 | 违反红线 2 |
| 每个决策日 T 重算 S(T) | 计算量为 O(N²)；冻结值在每个除权日都要换算，引擎要改；量化边界同样存在 |
| 只用原始价 | 除权日出现假跳空，误报警 |
| **F（本规格）** | 合规；计算一次；引擎代码不改 |

## 2. 锚日（D0-10）

- **定义**：该证券身份在**规范历史**中的第一根日线。规范历史的起点，在数据版本中登记。
- **锚日进入身份**：锚日写入证券的数据版本与每次运行的身份（manifest）。
- **子区间回放与截断测试**：沿用原锚日，不重新定基。
- **补入更早的历史**：锚日改变，作为新的数据版本，全部重算；旧版本保留。
- **锚日当日及之前的行动**：不作用于 F，记入复权日志，结果为"锚日行动，不作用"。
- 同一代码前后是不同公司的，按证券身份分开，各有锚日。
- **只用除权日不晚于 2019-12-31 的行动**：前向复权从来不需要更晚的行动。

## 4. 拆股

- 向后因子 b = split\_from ÷ split\_to。1 拆 2 时 b = 0.5；10 并 1 时 b = 10。
- 价格：F = R ÷ B；成交量：F\_V = V × ∏b（只乘拆股因子）。1 拆 2 之后，成交额 F × F\_V = R × V 不变。
- **字段**（D0-11、G-D0a-02）：
  - 原始成交量 `volume` 的语义不变，绝对成交额门槛读它；
  - 新增 `adj_volume` 存 F\_V，量价研究读它。
  - **`DailyBar.adj_volume` 放在字段末尾，类型为 `float | None`，默认值为空（None）**。空表示"没有调整量"，即未知；**不得默认为 0**，否则会把未知变成零成交（违反"缺失不等于零"）。现有不涉及成交量的夹具因此不必改动。需要调整量的模块遇到空值，一律记未知。
  - **落盘**：原始日线 CSV 增加一列 `adj_volume`（列名写入 02 号）。`raw_text.py` 的解析、`csv_raw_repository.py` 的 `BAR_COLUMNS` 与写出、**`csv_raw_reader.py` 的 `load` 与 `load_text` 两个读取入口**同步修改（D0R-02）。
  - **读法**（D0R-02）：缺这一列、或单元格为空，读为空（None）；文本 `0` 读为真实的零；非空但非法的值（无法解析、非有限、负数）报错，**不得当作缺失**。写出时空值写空单元格，零写 `0`，两者往返后保持区别。
  - 量价模块遇到空值记未知，**不得回退到原始 `volume`**。
  - 价格更正（第 9.1 节）只改原始开高低收，不改 `volume`，也不改 `adj_volume`（分红与价格更正都不影响 F\_V）。
- 拆股比例非正、缺失或无法解析：未解决的数据问题（第 6 节）。

## 5. 现金分红（D0-02、D0-03）

### 5.1 因子

**先映射生效日**（G-D0a-01）：所有行动（拆股与分红）先按第 5.5 节映射到**生效有效日** e′，即原始除权日当日（如为交易日且有日线）或之后的第一个有效日。**因子 b 作用于 e′**，B\_i 按 e′ 累乘；e′ 不晚于锚日的，按第 2 节不作用。下文的 e 指分红的生效有效日 e′，p 是 e′ 之前最近的有效日。

**判断拆股与分红的先后，用原始除权日**，不用 e′：缺价期间的拆股平移之后，可能与分红落在同一个 e′（夹具 A13），但它在事实上先于分红，分红金额按拆股后的每股计。记分红的原始除权日为 d。

对每个生效有效日 e：

1. **合并与分组**：同一**原始除权日**、同一每股单位、同一币种的现金分红记录，先求和，得到该组的 D。不同原始除权日的分红即使落到同一个 e′，也分组处理，不合并（D0R-01）。单位或币种不同的记录，不能直接相加：先换算到同一单位；换算不了，记未解决的数据问题。
2. **参考收盘** C\_ref：
   - 取除权日之前、同一历史段内最近一个有效日 p 的原始收盘 R\_p；
   - **换算到分红金额对应的每股单位**，分两种情形（G-D0a-01）：
     - **先于分红的拆股**（原始除权日 ∈ (p, d)）：金额按拆股后的每股计，C\_ref 必须乘这些拆股的 b。
     - **晚于分红的拆股**（原始除权日 > d，但平移后与分红同一个 e′）：金额按拆股前的每股计，C\_ref 不乘它的 b；它的 b 仍作用于 e′。
     - **同日拆股**（原始除权日 = d）：分红金额按拆股前还是拆股后的每股计，供应商之间可能不同。**已核实**为拆股后每股的（D0b 逐例核对：与除权日的价格跳空、第二来源的复权比率对照），再乘当日拆股的 b；**未核实的**，记 `SAME_DAY_BASIS_UNVERIFIED`，归未解决的数据问题（第 6 节），该证券在核实之前不可正式使用。
   - **同日口径的三支**（D0R-03）：
     - 已核实为**拆股后**每股：C\_ref 乘当日拆股的 b；
     - 已核实为**拆股前**每股：先把金额换成拆股后单位，D′ = D × b，再按上一支计算（两种写法结果相同：前收 100、同日 1 拆 2、旧股每股 1 元，与新股每股 0.5 元，都得 b\_div = 0.99）；
     - 未核实：拒绝，记 `SAME_DAY_BASIS_UNVERIFIED`。
     - 同一原始除权日有多次拆股、无法确定金额对应哪一阶段单位的：同样拒绝。
   - **同一缺价区间内的多笔分红**（D0R-01）：按原始除权日从早到晚依次处理。较晚一笔的参考价，要乘上更早各笔分红的 b\_div（以及其间拆股的 b），即用前一笔除权后的理论价。
   - 合起来，对原始除权日为 d 的一组分红：

     C\_ref = R\_p × ∏ { b ：原始除权日 ∈ (p, d) 的拆股与分红组 } ×（同日拆股按上述三支处理）

     原始除权日不晚于 p 的行动已经反映在 R\_p 中，不再乘。例：前收 100，两个缺价日依次除息 1、2，都落到下一个有效日：b₁ = 0.99，C\_ref₂ = 99，b₂ = 1 − 2/99，合计 0.97，与两笔同日合并（A12）相同。
3. **因子**：b\_div = 1 − D ÷ C\_ref。同一 e′ 上的各组因子与拆股因子相乘后作用于 e′。
4. 同一除权日既有拆股又有分红：B 在 e 处乘以 b\_split × b\_div。

### 5.2 缺价替代（D0-03）

p 不是 e 的前一个交易日（中间有缺价日）时，C\_ref 只是替代值，不等于真实的前一交易日收盘。记 `DIV_PREV_FALLBACK`，列为数据假设（待裁决 A-5）。同一历史段内找不到 p：未解决的数据问题。

### 5.3 类型与币种

| 情形 | 处理 |
| --- | --- |
| `CD`（常规现金分红） | 计入 |
| `SC`（特别现金分红） | 待裁决 A-2；产品经理建议计入 |
| 其他或为空 | 未解决的数据问题 |
| 币种：数据中没有币种字段 | 待裁决 A-3；产品经理建议作为**明确批准的数据假设**按 USD 处理，并逐只报告数量，不由"美国上市"推定已核实 |
| 币种明确不是 USD | 未解决的数据问题 |

### 5.4 异常

b\_div ≤ 0，或者 b\_div < 0.5：未解决的数据问题，人工核对。0.5 待批准（A-4）。

### 5.5 除权日不是交易日

作用于除权日之后的第一个有效日（生效有效日 e′），记 `ACTION_DATE_SHIFTED`；复权日志保留原始除权日。**平移后的 e′ 不晚于锚日 a 的**（包括原始除权日不晚于 a 的），按第 2 节作为锚日行动，不作用于 F（G-D0a-04）。拆股与分红用同一规则。

## 7. 数值规则（D0-01、D0-05、量化反例）

1. **计算上下文**：因子与 F 的计算都用固定的十进制上下文（`PARSE_CONTEXT`：28 位，HALF\_EVEN），中间不另行定点量化。28 位上下文下的除法与乘法本身也会舍入（例如 1/3），这是已知的、确定性的舍入，同一输入得到同一结果。
2. **最终量化**：
   - F 在最后一步量化到 6 位小数（HALF\_EVEN），再按现行入库规则转为 float；
   - F\_V 量化到 6 位小数。
3. **容差**：引擎的 ε\_p 在 F 坐标下按现行规定使用。17 号第 8 节的相对容差研究另行进行，不在本规格内。
4. **可表示性检查**（G-D0a-03）：对每根有效日线的**全部四个**复权价（开、高、低、收），量化之后检查：
   - 每个价格在 [0.01, 10⁹] 之内（界限拟议，待批准 A-6）；
   - 高低开收的关系照常成立（低 ≤ 开、收 ≤ 高；高 ≥ 低），即通过 `audit.explicit_failures` 的同样检查；
   - **振幅坍缩**：原始高 > 原始低，量化后却高 = 低的日子，只计数报告；单日坍缩本身不取消资格（真实波幅还包括与前收的差，跳空时仍可为正）。
   - **ATR 预检**（D0R-04）：在每个历史段内，对引擎与评价层实际使用的每个 ATR 窗口长度（以冻结配置为准，当前包括候选的 N 与评价的 ATR20），凡历史足够的窗口，都按量化后的 F 计算真实波幅与 ATR。发现 ATR ≤ 0 的，记录证券、日期与窗口长度，该证券不可正式使用。不补极小正数，不删除行情凑窗口；`indicators.atr` 现有的异常保护保留。
   - 任一项不通过，该证券**不可正式使用**。
   - 理由：例如累计拆股因子为 10⁶、原始价 0.40 时，F = 0.0000004，量化后为 0，现有 `quantize_price` 会直接拒绝。这不是边界上的小差异，而是数值无法表示；
   - 先检查后计算，不让运行中途失败：以上检查都在引擎运行之前完成。

## 10. 验证（D0-06）

1. **复权函数的前缀不变性**：对每只探索股、每个截断日 T（每个除权日及其前后各一个交易日，以及每月最后一个交易日）：只用截至 T 的日线与行动算出的 F、F\_V、复权日志，必须与用全部数据算出的结果的前缀**逐字节相同**。这验证了所测输入与所测截断日上的前缀不变性（D0R-06）；它是有限日期的测试，不是对所有输入的证明。
   - **复权日志的截断视图**（D0R-05）：比较的是"截至 T 已形成的记录"。原始除权日 ≤ T、但 e′ > T 的行动，在截断运行中是**待处理**状态（记原始除权日、金额与"待处理"，没有 e′）；全量运行中这条记录的 e′ 与处理结果属于 T 之后的信息，不得回填到截至 T 的视图。比较时，全量日志先按同一规则还原为截至 T 的视图，再逐字节比较。
   - 截断日另外包括：缺价区间的中间日、历史断点前后、存在待处理行动的日子。
   - 另两项分开陈述，不由本项代替：复权函数构造上只读截至 i 的行动（因果论证）；行动记录在历史当时是否真实可得（第 3 节，数据假设）。
2. **引擎前视**：M0b 的事件锚点前视测试，在新数据上照常运行并通过。
3. **领域纯净**：复权函数通过 M0b 的领域纯净扫描。
4. **诊断**（不作验收依据）：在同一组截断日上，以 S(T) 的前缀运行引擎，与 F 运行的前缀比较离散摘要，逐项报告差异与首次差异日。
5. **数据核对**（沿用计划 v3 WP3 D0b 第 3、4 项）：
   - Tiingo 与新序列的差异分布；
   - 双源离散对照；
   - 同日拆股与分红的金额口径逐例核对（第 5.1 节）；
   - 除权日跳空与因子的一致性核对。

   不读取 2020 年以后的任何信息。
