## 1. D-01 规格（v4）

### 1.1 开关、合法组合与禁用语义

| 开关 | 取值 | 关闭时 | 打开时 |
| --- | --- | --- | --- |
| `x1` | 0 = 关；8% / 10% | 不检查 DD ≥ x₁ | S 路径要求 DD\_T ≥ x₁ |
| `r2_floor` | OFF / ON | R2 照旧 | R 路径要求 DD\_T ≥ x₁ |
| `x2` | 0 = 关；15% / 20% | 不检查 DD ≥ x₂ | 所有进入警戒的转移要求 DD\_ep ≥ x₂；a 增加百分比分支 |
| `t11_full` | OFF / ON | T11 = 回吐 ≥ k₁ | T11 = 回吐 ≥ k₁ 且完整警戒条件 |
| `long_path` | OFF / X1 / X2 | 不计算长窗口 | L 路径门槛 x\_L = x₁（X1）或 x₂（X2） |
| `release_hyst` | OLD / EFFECTIVE | a′ = D\_ep < k₁ | a′ = Δ < h × θ，θ 按启动路径取（第 1.4 节）；h = 0.5（固定探索假设） |
| `rec_scale` | OFF / PRICE | 现行强恢复公式 | 恢复侧使用 ATR\_rec |

**合法组合（采纳 R3-Q1）。** 参数对象构造时检查，违反任何一条立即报错，**不自动调整**：

1. `x2 > 0` ⇒ `t11_full = ON`。
2. `long_path = X1` ⇒ `x1 > 0`；`long_path = X2` ⇒ `x2 > 0`。
3. `r2_floor = ON` ⇒ `x1 > 0`（否则该开关无意义，作为配置错误拒绝）。
4. `x1 > 0` 且 `x2 > 0` ⇒ `x2 > x1`。
5. 0 < h ≤ 1。

`t11_full = ON` 且 `x2 = 0` 是合法组合：此时警戒只按 ATR 判断，T11 要求回吐 ≥ k₁ 且 D\_ep ≥ k₂。T06 的 600 套对照全部满足上述约束（第 3.1 节）。

**禁用语义**

- **合取式条件**（"且 DD ≥ x"）：x = 0 时整项删除。
- **析取式分支**（a 的"或 DD\_ep < x₂"）：x = 0 时该分支删除，即视为不成立。a′ 的禁用语义见第 1.4 节 θ 的定义（x₁ = 0 时，θ 中的百分比项删除）。
- `release_hyst = OLD` 时，a′ 完全使用旧式，不受 x₁ 影响。

全部开关关闭（x₁ = x₂ = 0，`t11_full`、`long_path`、`r2_floor` 为 OFF，`release_hyst` = OLD，`rec_scale` = OFF）即 **V0**，必须与 v0.7.1 及正式运行 `20261014T015654-dc5b14c` 逐项相同。

**验收方式**（采纳 R3-Q1）：合法组合由第 4 节的夹具检验行为；非法组合由 S36 检验拒绝执行。

### 1.2 记号

- **短窗口**：当前历史段内、last\_release 当日及之后、含当日的最近 W = 63 条有效日线。P^max、D\_T 照旧，并记 DD\_T = 1 − C / P^max。
- **长窗口**：当前历史段内、last\_release 当日及之后、含当日的**最近 252 条有效日线**，不足 252 条时取全部；独立于短窗口。P^max\_L 并列取最近一日；DD^L\_T = 1 − C / P^max\_L。252 条有效日线不等同于自然一年。
- **预警期间**：DD\_ep = 1 − C / P\_ep；跌幅 Δ = P\_ep − C；E₁ = max(k₁ × ATR\_ep, x₁ × P\_ep)，E₂ = max(k₂ × ATR\_ep, x₂ × P\_ep)。
- **完整警戒条件**：Δ ≥ E₂，即 D\_ep ≥ k₂ 且 DD\_ep ≥ x₂。
- **比较容差**：DD 与 x 的比较使用 ε\_r，与 D 的比较相同。

### 1.3 启动（无预警时，按序取首条成立的路径）

| 序 | 路径 | 条件 | 冻结基准 |
| --- | --- | --- | --- |
| 1 | S | D\_T ≥ k₁ 且 DD\_T ≥ x₁ | 短窗口的 P^max 及其日期；A\_start 照现行规则 |
| 2 | R | R2 触发，且（`r2_floor` = ON 时）DD\_T ≥ x₁ | 同 S |
| 3 | L | `long_path` ≠ OFF 且 **DD^L\_T ≥ x\_L** | 长窗口的 P^max\_L 及其日期；A\_start 见下 |

**修改：L 路径删去 v2 的"且 D\_T ≥ k₁"**

- **理由。** 在阴跌中，短窗口的 D\_T 约为"62 日跌幅 ÷ ATR"。日跌幅低于 ATR/价格 ÷ 31 时，D\_T 永远达不到 2。F7（每日跌 0.03，ATR 约 2.03）中 D\_T 稳定在 0.92，v2 的 L 路径永不启动。v0.7.1 在 F7 中同样永不启动，这是现行规则本来就有的漏报，不是 v0.8 引入的。
- 这个附加条件原本的目的，是不在价格反弹到短期高点时启动。R2-Q2 已指出它的含义只是"仍低于近期高点足够距离"，并不表示仍在下跌。删去后，L 路径的含义就是"自上次解除以来（或最近 252 条日线内）的累计跌幅已达 x\_L"，可能在上涨日启动（见 S29）。
- **反复启动。** last\_release 截断避免旧高点直接重复触发；再次启动仍可能在后续新一轮回撤中发生（R4-Q2 的措辞）。
- **剩余漏报**（如实列出，交由发起人裁决）：最近 252 条有效日线内的累计跌幅始终不到 x\_L 的下跌，不提醒。F7 在 x₁ = 8% 时第 447 日才启动，x₁ = 10% 时 460 日内不启动。

**L 路径的 A\_start（采纳 R3-Q2）**

- PEAK 分量：取 ATR\_N(P^max\_L 日)。该日 ATR 不可得（不足 N + 1 条日线）时，取 [P^max\_L 日, T] 内最早一个 ATR 可得日的 ATR，作为**替代尺度**。它不代表峰值当时的波动；若这段时间已包含上市初期的暴跌，尺度可能明显偏大。
- atr\_basis = PEAK：A\_start = PEAK 分量。atr\_basis = MIN：A\_start = min(PEAK 分量, ATR\_N(T))。
- **START 依据分开记录以下字段**，不让一个字段兼表两义：
  - `p_ep_day`：原峰值日，不替换；
  - `peak_atr_available`：峰值日的 ATR 是否可得；
  - `peak_component_atr_day` 与 `peak_component_atr`：PEAK 分量的来源日与值；
  - `atr_t`：启动日的 ATR；
  - `a_start_selected`：最终选中的来源，取 PEAK\_COMPONENT 或 T，PEAK 时恒为 PEAK\_COMPONENT。
- 短窗口不会出现 ATR 不可得：可计算要求至少 W + N 条日线，短窗口最早一条的下标 ≥ N。

**初始等级与原因代码（R4-Q3）**

- 初始等级：以冻结后的基准判断，完整警戒条件成立为警戒，否则为关注。
- 原因代码按**启动当日哪些路径的条件真实成立**分配，不按等级或 D 值推断：

| 当日成立的路径 | 记录的原因 |
| --- | --- |
| S | 初始为警戒时记 `R1_GE_K2`，否则记 `R1_GE_K1` |
| R | `GAP`；可与 S 的原因并列 |
| 只有 L（S、R 都不成立） | `R1L_CUMULATIVE` |

- 冻结基准按第 1.3 节的顺序（S > R > L）取首条成立的路径。L 与 S 或 R 同时成立时，不记 `R1L_CUMULATIVE`，但在事件数值中记录 dd\_l。
- 例（R4-Q3）：短窗口峰值 100、ATR 0.5、C 97，D\_T = 6，DD 3% < x₁，S 不成立；R2 成立且 `r2_floor` = OFF。原因只记 `GAP`，初始等级按完整警戒条件判断为关注（DD 3% < x₂）。
- 事件数值另记 dd\_t、dd\_l、x₁、x₂、entry\_path。V0 下 S 即 D\_T ≥ k₁，初始警戒即 D\_T ≥ k₂，原因代码与 v0.7.1 相同。

**a′ 的回滞门槛 θ（R4-Q2 修订）**

启动时新增并冻结两个字段：`entry_path`（S / R / L，即冻结基准所取的路径）与 Δ\_start = P\_ep − C\_start（启动日的跌幅）。

| entry\_path | 入口门槛 E\_entry | θ |
| --- | --- | --- |
| S | E₁ = max(k₁ × ATR\_ep, x₁ × P\_ep) | min(E\_entry, Δ\_start) |
| R | E₁ | min(E\_entry, Δ\_start) |
| L | x\_L × P\_ep | min(E\_entry, Δ\_start) |

a′（EFFECTIVE）：Δ < h × θ。x₁ = 0 时，E₁ 中的百分比项删除。

- **原则**：解除所需的回升，以"启动时实际越过的门槛"为基准，并且**不超过启动时已有的跌幅**。因此 a′ 在启动时不可能已经成立，必须先有回升。
- S 路径：启动时 Δ\_start ≥ E₁，θ = E₁，与 v3 相同。
- L 路径：启动时 DD^L ≥ x\_L，且 P\_ep = P^max\_L，所以 Δ\_start ≥ x\_L × P\_ep，θ = x\_L × P\_ep，即 a′ 为 DD\_ep < h × x\_L。这采用了 R4 建议的形式。
- R 路径：跳空启动时跌幅可能小于 E₁，甚至小于 h × E₁。取 min 后，a′ 要求至少收复启动跌幅的一半（h = 0.5）。v0.7.1 中 GAP 启动当日 D\_ep < k₁ 时 a′ 立即成立（S19 的路径），这是旧规则已有的"不涨即解除"。EFFECTIVE 一并修正，OLD（V0、V1）保留旧行为。
- **V1 的已知副作用**：V1 保留旧 a′，L 路径启动的预警若 D\_ep < k₁，会在 d 日后不涨即解除（S37c）。V1 是刻意的对照，T06 报告中单列这类解除，不把它们算作 L 路径的效果；L 路径的实际效果以 V3、V4 为准。

**T10 的证明**（R3-Q3 已同意，补前提）。前提：`t11_full` = ON，x₂ 贯穿 T6、T9、T11，且**同一次回放内参数不变**。设第一次进入警戒的日子为 s。s 之前没有降级过，所以 s 必为 T6 或 T9，完整警戒条件在 s 成立。L\_ep ≤ C\_s；今日新低 C < L\_ep，因此 D\_ep、DD\_ep 都严格大于 s 日。

跨版本比较必须重新回放，不得把旧状态套入新规则。

**反复。** 降级后再升级需要新的恶化证据，这减少一部分边界反复，但不保证没有反复。T06 照常报告降级、加重次数与路径。

### 3.2 两张表，不做互斥分类

**(1) 逐日覆盖表**

- 每行一个（证券, 交易日），只取双方都可计算的日子。字段：双方的显示状态、等级、episode\_id。
- 缺价、不可计算、数据中断另表列出，不进入比较。
- 汇总四格：双方都有预警、只有 V0、只有新变体、都没有。
- "失去覆盖""新增覆盖"只在这张表上定义。

**(2) 事件对照表**

每条记录允许多个标签。

- **基准启动后的通知等待**：对每个 V0 的 START，记录：
  - 新变体当日是否已有进行中的预警（若有，标"已有预警"，记其 episode\_id）；
  - 若没有：随后 20 个、60 个有效交易日内新变体首次 START 的日期与等待日数，期间最低收盘及其相对 V0 启动收盘的跌幅。
  - 窗口内没有 START 的，标"20 / 60 日内无通知"。
  - 窗口不足、退市、数据中断的，标"窗口不完整"，单列。
  - 不称为"延迟"。
- **反向**：对每个新变体的 START，记录 V0 当日是否已有预警；若没有，同样记录 V0 随后的首次 START。
- **加重**：对每个 V0 的 ESCALATE，记录新变体当日的状态，取以下之一：正常、关注、警戒、不可计算、缺价（冻结）、数据中断（R4-Q4）。不是警戒的，记录随后 20 / 60 日内新变体是否进入警戒及期间路径。即"被取消的加重"。
- **解除**：对每个 V0 的 RELEASE，记录新变体当日的状态；反之亦然。
  - **只有当一次 V0 预警与一次新变体预警互为唯一重叠时**，才计算解除日期差。
  - 其余情形标"多对多"，不强行计算。
- **重叠映射表**：列出全部重叠关系，允许多对多。**重叠按双方实际处于预警（日末等级为关注或警戒）的日子判断**；解除日日末已为正常，不算重叠（R4-Q4）。

### 3.3 单项贡献：只比较仅一个开关不同的配对

现有 600 套已包含以下全部配对，不增加回放：

| 开关 | 配对 |
| --- | --- |
| `r2_floor` | V1、V3、V4 内，其他设置完全相同的 OFF / ON |
| `long_path` | X1 / X2（其他相同） |
| `x1` | 8% / 10%（其他相同） |
| `x2` | 15% / 20%（其他相同） |
| `release_hyst` | V1 与 V3 中设置相同的两套；另有 V0 与 V2 |
| `rec_scale` | V3 与 V4 中设置相同的两套 |

V0 → V1 同时改变了 x1、x2、t11\_full、long\_path，这是一组**捆绑改动**；在它内部只能通过上表的配对作部分归因。

**被过滤的 R2**，在 `r2_floor` OFF / ON 的配对中逐条分类：

- (i) 当日 GAP 证据被过滤，但同日或随后由其他路径启动：记日期差；
- (ii) OFF 中的 START 在 ON 中被取消：按"基准启动后的通知等待"记录后续首次通知的日期、期间的进一步跌幅，或"始终没有后续通知"（至观察终点）。

标签允许多个并存；报告时**另行给出被过滤的 R2 日数**，不把各标签的数量相加当作被过滤通知的总数（R4-Q4）。
