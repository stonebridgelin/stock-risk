## 1. 主要研究假设

**H-VP（主假设）**：在价格规则保持不变的前提下，恢复观察发出的当天就已知的量能证据，能否区分两类恢复：之后仍有明显下跌的，与恢复延续的？

**分组用的证据**，都在恢复观察日 r 收盘时已知：
- **A1**：本观察周期起点的那次新低，其下跌段量能是否比前一段减弱；
- **A3**：r 之前几日的上涨日是否放量。

**结果**，都在 r 之后才发生：
- 回踩是否未破坏恢复结构（A4）；
- 是否再跌破参考低点；
- 恢复失败与撤销；
- 到解除的等待；
- 解除后的不利变化。

**与项目目标的关系**：
- **及时预警**：本假设不改启动条件，成交量不是预警的前提。第一阶段不影响 S1、H1。
- **恢复跟踪**：主要作用点。
- **及时解除**：只有第一阶段显示出稳定差异，才另行提出是否改变解除条件（第 4.5 节）。

**本轮不研究**：
- 上涨中的高点背离与报警一侧的量价用法（第 7 节问题 5）；
- OBV、CMF、MFI 等累计或振荡类指标（第 2.4 节末）；
- A4 形成之后的地标分析（第 4.2 节）。

## 2. 候选定义

**通用约定**：
- 价格一律用**收盘价**，与引擎的 L\_ep 与"今日新低"一致；
- "有效日"指有日线的交易日；
- 所有窗口只在同一历史段内取数。窗口需要跨越断点时，记 `CROSS_BREAK`（未知）。

### 2.1 相对成交量 V0

> RVOL\_t = V\_t(t) ÷ 中位数（V\_{t−1}(t), …, V\_{t−m}(t)）

- V\_j(t)：第 j 日成交量换算到截至 t 的单位（第 3.1 节）。
- 分母取 t 之前**最近 m 个成交量已知的有效日**，不含当日。
- **分母不足**：同一历史段内成交量已知的有效日少于 m 个，记未知，原因 `RVOL_BASE_SHORT`。不缩短窗口。
- **当日成交量缺失**：记未知，原因 `VOLUME_MISSING`。
- **分母为 0**（m 日全是零成交量）：记未知，原因 `RVOL_BASE_ZERO`。
- 只登记中位数这一种。均值是另一个定义，本轮不试。

### 2.2 下跌段量能减弱 A1

**锚点**：同一预警、同一历史段内，引擎记录为"今日新低"的日子，按时间顺序记为 n₁ < n₂ < …。启动日不是锚点，除非它本身被记录为新低。

**比较对象**：对每个 i ≥ 2，取 t₂ = nᵢ，t₁ = nᵢ₋₁，即相邻的两个新低锚点。第一个锚点 n₁ 没有可比较的前一锚点，记不比较，原因 `FIRST_ANCHOR`。

**第二段**：
- h₂ = 开区间 (t₁, t₂) 中收盘最高的日子，并列取最早。
- **开区间为空**（两个锚点是相邻有效日）：不比较，原因 `NO_REBOUND`。
- **反弹不足**：C\_{h₂} − C\_{t₁} < r × ATR\_ep，不比较，原因 `NO_REBOUND`。ATR\_ep 取 t₂ 当日引擎记录中的值。
- 第二段 = (h₂, t₂] 中的下跌日，即 C\_j < C\_{j−1} 的日子。

**第一段**：
- 若 i − 1 ≥ 2：h₁ = 开区间 (nᵢ₋₂, t₁) 中收盘最高的日子，并列取最早；开区间为空时，h₁ = nᵢ₋₂。
- 若 i − 1 = 1（t₁ 是第一个锚点）：h₁ = 本预警的峰值日 p\_ep（引擎字段 `p_ep_day`）。
- 第一段 = (h₁, t₁] 中的下跌日。

**量能**：
- 每段取其下跌日 RVOL 的中位数；RVOL 一律以 t₂ 为换算基准（第 3.1 节）。
- 任一段的下跌日少于 2 个：不比较，原因 `LEG_SHORT`。
- 两段中任一下跌日的 RVOL 未知：记未知，原因随 RVOL。不删去那一日。

**成立**：第二段中位数 ≤ ρ × 第一段中位数。

**形成时点**：t₂ 当日收盘后。只用 t₂ 及以前的数据，不需要右侧确认。它说的是"这一次新低之前的下跌，量能比上一段弱"，不说 t₂ 是谷底。

**名称**：报告中称"反弹后再创新低时，下跌段相对量能减弱"，不称"双底"或"二次探底成功"。它不覆盖没有跌破前低的回踩。

**解释上的限制**：A1 比较的是相对正常水平的活跃度，不是绝对成交量。正常量与下跌量同时减半时，A1 可能不成立。这是否符合发起人的经验，见第 7 节问题 2。

### 2.3 企稳 A2

不新定义，直接用引擎的"企稳"（since\_obs ≥ K）与 STABILIZED 事件。A2 记录的是：本周期是否已经企稳、在哪一天。

### 2.4 上涨日放量 A3

- **时点**：恢复观察 RECOVERY\_OBS 发出的当日 r。
- **窗口**：[r − k + 1, r] 中的 k 个有效日，必须都在本观察周期内（不早于 obs\_start）。不足 k 个时记未知，原因 `A3_WINDOW_SHORT`。
- **上涨日**：窗口内 C\_j > C\_{j−1} 的日子。
- **少于 2 个上涨日**：记"结构不可比"，原因 `A3_FEW_UP_DAYS`。它不同于"不成立"。
- **任一上涨日的 RVOL 未知**：记未知。
- **成立**：上涨日 RVOL 的中位数 ≥ θ。
- **形成时点**：r 当日收盘后。

**为什么不用 OBV**：
- 它与 RVOL 用同一份成交量，不是独立证据；
- 它对个别巨量日敏感；
- 首轮只要一种背离定义（A1）。

### 2.5 回踩未破坏恢复结构 A4（作为结果，不用于分组）

- **参考低点**：冻结为 r 当日的 L\_ep，记为 L\*。
- **观察窗口**：r 之后的 J 个有效日。**预警解除不截断**这个窗口，解除之后照常按价格观察（VP-03）。
- **违反**：窗口内任一日收盘 < L\* − ε\_p（ε\_p 与引擎的价格容差相同）。
- **判定优先级**（VP-04）：
  1. **已知违反优先**：一旦出现违反，记"不成立"，原因 `BROKE_REF_LOW`，之后无论截断与否都不改；
  2. 窗口完整、没有违反，再看结构：
     - 窗口内没有下跌日：记"结构不可比"，原因 `NO_PULLBACK`；
     - 有下跌日但没有上涨日：记"结构不可比"，原因 `NO_UP_DAY`；
     - 窗口内所需日子的 RVOL 有未知：记未知；
     - 否则，下跌日 RVOL 中位数 < 上涨日 RVOL 中位数，记"成立"；不满足，记"不成立"，原因 `PULLBACK_VOLUME_HIGH`；
  3. 窗口没有走完（数据断点、数据终点、缺价），并且此前没有违反：记未知，原因 `A4_TRUNCATED`。
- **例子**：
  - J = 10，第 2 日收盘跌破 L\*，第 5 日遇到数据断点：记"不成立"（`BROKE_REF_LOW`），不是未知；
  - J = 10，第 6 日预警解除，第 1–10 日都没有跌破 L\*：照常判定结构与量能，不因解除记未知。
- **引擎事件**：RECOVERY\_FAIL、RECOVERY\_REVOKED 只在预警存续期间有意义，在第 4.3 节作为另外的结果单独计数，不用"没有事件"代替"恢复成功"。

### 2.6 绑定、快照与终止（VP-07）

- **绑定**：每条证据记录带（证券、预警编号 `episode_id`、周期 `cycle_no`、恢复观察序号 `obs_n`、价格配置身份）。
  - A1 绑定到它所在的新低锚点 t₂。新低会触发观察重置，所以 t₂ 正是新周期的起点。
  - A3、A4 绑定到恢复观察记录（`episode_id`、`cycle_no`、`obs_n`）。
- **周期起点的 A1 状态**：一个周期若由新低开启，它的 A1 状态就是该新低的 A1 结果；若由加重或缺价开启，记"不适用"，原因 `CYCLE_NOT_NEW_LOW`。
- **快照**：A1、A3 在形成日的结果保存为历史快照，此后不改。
- **当前是否仍有效**：快照之后，下列任一发生即"不再有效"，分别记录终止方式：
  - `REVOKED`：RECOVERY\_REVOKED；
  - `FAILED`：RECOVERY\_FAIL；
  - `RESET`：观察重置（新低、加重、缺价）；
  - `RELEASED`：预警解除；
  - `DATA_BREAK`：数据断点。
- **证据链**：同一恢复观察记录上，A1（周期起点）→ A2（本周期企稳）→ A3（r 日）依次成立，记"r 日证据链完整"；A4 是之后的结果。不同周期、不同恢复观察的记录不得拼接成一条链。

## 3. 数据要求、无前视与异常处理

### 3.1 成交量单位与拆股

- 决策日 T 要比较的所有成交量，统一换算为截至 T 的股数单位：

  > V\_j(T) = V\_j(原始) × 所有除权日在 (j, T] 内的拆股比例之积

  1 拆 2 时比例为 2。
- 分红不调整成交量。
- 不同决策日的换算结果各自独立，不拼接。
- 保留原始成交量、换算因子、公司行动记录的来源，以及每个决策日当时形成的证据。重算只新增版本，不覆盖。
- **可得性（VP-08，待裁决）**：
  - v1 写的是"只用除权日之前已经公告的拆股"，来自发起人已采用的红线澄清。但现有数据（`Split` 模型）只有执行日与比例，没有公告时间，这一条无法逐条核验。
  - 而且对复权的正确性来说，它也不是必要条件：除权日当天的行情已经反映了拆股，到当日收盘时，这次拆股已经生效，也能从行情中观察到。
  - **产品经理建议**把红线澄清改为："第 t 日的信号只使用除权日不晚于 t 的公司行动；除权日当日收盘时，行动已生效、可从行情观察到，不另要求证明公告时间。"
  - 发起人裁决之前，按原澄清执行。D0a 规格中写明证据要求：保存公司行动的来源与执行日；如果数据源提供公告日，一并保存。

### 3.2 异常与缺失

| 情形 | 处理 |
| --- | --- |
| 缺价日（没有日线） | 不是有效日；不进入任何计算。窗口需要它时，按各定义处理（A4 记 `A4_TRUNCATED`） |
| 有日线但成交量缺失 | 未知（`VOLUME_MISSING`）；不进入分母；所需窗口含它的，相应证据记未知，不删日 |
| 成交量为 0 | 已知值；进入分母；单独计数；使分母为 0 时记 `RVOL_BASE_ZERO` |
| 异常大值（拟议：大于此前 m 日中位数的 50 倍） | 不删除，照常计算，标 `VOLUME_OUTLIER` 供核对 |
| 半日市 | 照常计算，标 `HALF_DAY`。A3、A4 窗口内含半日市的，结果照常判定，另报含半日市的记录数 |
| 数据断点 | 新历史段重新积累 RVOL 分母；跨断点的窗口记 `CROSS_BREAK` |
| 财报日等巨量日 | 没有财报日历，不能标记；不删除 |

### 3.3 数据来源与核验

- 只用授权的探索数据，截至 2019-12-31，不触碰封存期。
- 只用一个数据源（D0b 之后为 Massive），不混用 Tiingo 的成交量。
- 记录数据源成交量的统计范围（是否合并成交量、是否含盘前盘后），查不到的记"未知"。
- **关键日期单独核对**：A1、A3 成立日、`VOLUME_OUTLIER` 日与拆股附近，在授权范围内与第二来源比对。不能用全样本差异的中位数代替。

### 3.4 证据只陈述，不回流

- A1–A3 只在形成日收盘后、用截至当日的数据计算。
- 评价时可以用事后的谷底、F\_ref 等评价层信息，但这些信息不得回流到证据计算（红线 2）。
- 措辞只用"下跌段相对量能较前一段减弱""恢复前几日的上涨日相对放量"这类陈述。

## 4. 价格基线与对照设计

### 4.1 零干扰

- **价格配置**：首轮只用 R0（网格序号 385、V0 开关、探索假设），规则与事件不变。
- **量价模块**：独立的纯函数，输入为（换算后的日线、生命周期逐日记录与事件），输出为证据记录，不写回任何生命周期状态。
- **验证**：
  - 开启与关闭量价模块，生命周期输出的全语义摘要相同（M0b）；
  - 输入的日线、事件与配置对象在调用前后相同，没有被原地修改。
  - 这只证明测试过的输入上没有干扰，不宣称对所有输入都成立。

### 4.2 分组与结果（VP-01）

**分析单位**：恢复观察记录（每一个 RECOVERY\_OBS）。

**分组**：只用 r 日已知的证据：
- A1 状态：成立 / 不成立 / 不比较（按原因） / 未知 / 不适用；
- A3 状态：成立 / 不成立 / 结构不可比 / 未知；
- r 日证据链：完整 / 不完整。

**结果**：都从 r 之后开始计：

| 代号 | 结果 | 窗口与截断 |
| --- | --- | --- |
| O1 | A4 的结果（第 2.5 节） | J 日；规则见第 2.5 节 |
| O2 | 收盘跌破 L\* − ε\_p | (r, r + Y\_rec]；已知违反优先；未见违反又未走完记未知 |
| O3 | 预警存续期间发生 RECOVERY\_FAIL 或 RECOVERY\_REVOKED | 同上窗口；预警先解除且此前没有这两个事件的，单列为"已解除，不适用"，不记为"没有失败" |
| O4 | 到 RELEASE 的有效日数 | 截至 Y\_rel；未解除的单列"截至窗口未解除"，不当作 Y\_rel |
| O5 | 该预警此后第一次 RELEASE 的解除后不利（p、p\_L 的现行定义） | 按 17 号第 3C 节；窗口不完整的按协议处理 |

**A1 的辅助分析**（分析单位改为新低锚点 t₂）：
- 结果为 (t₂, t₂ + Y\_low] 内是否再创收盘新低；
- 已知违反优先，未走完记未知。

**不做**：
- 用 A4 分组再比较恢复失败率。A4 成立组在 J 日内的失败率为零是定义造成的，不是量能信息；
- A4 形成之后的地标分析：以 L = r + J 为起点，只比较 L 时仍可观察、此前没有违反的记录。这是另一项分析，首轮不做；将来要做，另行登记。

### 4.3 统计协议

- 每个分组报告：记录数、所属预警数、证券数；各结果的"是 / 否 / 未知 / 不适用"分母分别列出。
- **两种汇总**：
  - 全部记录合并；
  - 证券等权：先按证券求比例，再取证券间的平均。
- 另报每只证券的明细表。
- 同一预警的多条记录不是独立样本。首轮只作描述，不做显著性检验，不报 p 值。
- 只在同一价格配置（R0）内部比较。

### 4.4 必报的数量

- 观察记录数、独立预警数、证券数；
- 从未解除、观察窗口不足、解除后窗口不足的记录数；
- 每种原因代码的数量。

### 4.5 第二阶段（另行提出，不在本草案批准范围内）

只有第一阶段在探索集上显示出一致的差异，才可能提出状态机改动。届时：
- 带量能与不带量能两个版本，在相同数据、相同价格规则、相同口径下比较，一次只改一个机制；

## 6. 风险、副作用与不采用的条件

**风险**：
1. **样本小**：27 只探索股中可比的记录可能很少，只作描述。
2. **缩量没有方向**：可能是抛压减弱，也可能是无人交易。
3. **定义灵活**：预算上限与台账防止在探索集上调出好看的结果。
4. **数据问题集中在关键日**：拆股附近、半日市、异常量。
5. **误导性安心**：证据第一阶段只进内部报告。
6. **将来改解除**：可能更晚或更早、反复更多，还可能违反 H1。

**不采用或延期的条件**（拟议，在 T08c 冻结前判断）：
- 关键日核验不通过，或者成交量统计范围无法确认；
- A1、A3 的"不比较、未知、结构不可比"合计占恢复观察记录的比例过高（比例待批准；分母为 R0 在探索集上的全部恢复观察记录）；
- 各分组之间看不出一致的差异，或者差异方向在多数证券上不一致；
- 9 个组合用完，仍没有清楚的结论。

出现任一条，量价方向本轮延期，记入台账，不为赶冻结降低要求。
