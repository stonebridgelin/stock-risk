## 1. 主要研究假设

**H-VP（主假设）**：在价格规则保持不变的前提下，量能证据能否区分两类恢复过程——后续仍有明显下跌的，与恢复延续的？

具体是两个可以检验的问题：
1. **下跌段**：价格创出新的本次低点时，如果这一段下跌的量能比前一段明显减弱（A1），之后再创新低的比例、再跌的幅度，是否低于量能没有减弱的新低？
2. **恢复段**：恢复观察（RECOVERY\_OBS）发出时，如果恢复得到成交量支持（A3），并且之后回踩没有破坏恢复结构（A4），恢复失败（RECOVERY\_FAIL）的比例、到解除的等待、解除之后的不利率，是否不同于没有量能支持的恢复？

**与项目目标的关系**：
- **及时预警**：本假设不改变任何启动条件，也不让成交量成为预警的前提，所以第一阶段不影响 S1、H1。
- **恢复跟踪**：这是主要的作用点。现有的恢复观察只看价格，量能证据可能说明恢复的"质量"。
- **及时解除**：只有在第一阶段的诊断显示出稳定差异之后，才另行提出是否改变解除条件（第 6 节）。

**本轮不研究**：
- 上涨中的高点背离与报警一侧的量价用法。原因是发起人强调的证据链是"下跌 → 恢复"这一侧；报警一侧是否研究，见第 7 节问题 5。
- OBV、CMF、MFI 等累计或振荡类指标。原因见第 2.4 节。

## 2. 候选定义

### 2.1 基础量：相对成交量 V0

对第 t 个有效交易日：

> RVOL\_t = V\_t ÷ 中位数（V\_{t−1}, …, V\_{t−m}）

- 分母取此前 m 个**有效成交量日**，不含当日。
- **用中位数，不用均值**，理由是财报日等巨量日会把均值拉高。只登记这一种。如果以后要试均值，作为另一个方案登记。
- 分子与分母中的成交量统一到**截至 t 已生效拆股**的同一股数单位（第 3.1 节）。
- 只在同一历史段内取数。断点之后，新历史段满 m 个有效成交量日之前，RVOL\_t 为"未知"。
- 分母为 0（m 日内全是零成交量）时，RVOL\_t 为"未知"，不按无穷大处理。

### 2.2 下跌段量能减弱：A1

**比较对象**：同一预警（episode）内，相继的两个"本次低点"及其前面的下跌段。

- 价格用**收盘价**，与引擎的 L\_ep（P\_ep 以来的最低收盘）和"今日新低"的判定一致。最低价不用，理由是它容易受单日插针影响，而且引擎的状态都按收盘定义。
- **识别**：
  - 设 t₂ 为一个"今日新低"日（引擎的 `new_low` 为真）；
  - t₁ 为 t₂ 之前、同一预警内上一个"今日新低"日（或者预警的启动日，如果此前没有新低）；
  - h 为 (t₁, t₂) 之间收盘最高的一日（并列取最早）；
  - **两段之间必须有像样的反弹**：C\_h − C\_{t₁} ≥ r × ATR\_ep。不满足时，t₂ 只是连续下跌的延续，不形成 A1 的比较，记"无比较"。
- **两段的量能**：
  - 第一段 = [前一个反弹高点或 P\_ep 日, t₁] 中下跌日（C\_j < C\_{j−1}）的 RVOL 中位数；
  - 第二段 = [h, t₂] 中下跌日的 RVOL 中位数；
  - 两段都在 t₂ 当日用截至 t₂ 的单位重新换算（第 3.1 节）；
  - 两段任一段的下跌日少于 2 个，记"无比较"。
- **成立**：第二段 ≤ ρ × 第一段。
- **形成时点**：t₂ 当日收盘后，只用 t₂ 及以前的数据，**不需要右侧确认**。它说的是"这一次新低的下跌量能比上一段弱"，不说 t₂ 是谷底。
- **失效**：A1 只是附在 t₂ 这个新低上的证据，不持续；下一次新低按同样规则重新判断。
- **适用位置**：只作诊断。

### 2.3 企稳：A2

不新定义。直接用引擎现有的"企稳"：观察起点以来 since\_obs ≥ K（10 号规格第 1.3 节），对应事件 STABILIZED。A2 只要求它发生在 A1 成立的那次新低之后、同一观察周期内。

### 2.4 恢复得到成交量支持：A3

- **时点**：恢复观察 RECOVERY\_OBS 发出的当日 r，即恢复确认由假变真。
- **成立**：[r − k + 1, r] 中各有效日 RVOL 的中位数 ≥ θ。
- **形成时点**：r 当日收盘后。
- **失效**：同一观察周期内发生观察重置（新低、加重或缺价）即失效；下一次 RECOVERY\_OBS 重新判断。
- **适用位置**：只作诊断。

**为什么不用 OBV**：
- OBV 把整日成交量记为正或负，与涨跌幅无关，对个别巨量日敏感；
- 它与 RVOL 用的是同一份成交量，不是独立证据；
- 首轮只要一种背离定义（A1），OBV 列为将来的备选，需要时另行登记。

### 2.5 回踩未破坏恢复结构：A4

- **观察窗口**：r 之后的 J 个有效交易日。
- **成立**：同时满足以下三条：
  1. 窗口内没有"今日新低"，没有 RECOVERY\_FAIL；
  2. 窗口内至少有一个下跌日（否则没有"回踩"可言，记"无回踩"）；
  3. 窗口内下跌日的 RVOL 中位数 < 窗口内上涨日的 RVOL 中位数。
- **形成时点**：r + J 日收盘后。如果在此之前出现新低或恢复失败，当日即记"不成立"。
- **窗口被截断**：窗口内遇到数据断点、数据终点或预警解除，A4 记"未知（窗口不完整）"，不记成立，也不记不成立。
- **适用位置**：只作诊断。

### 2.6 证据链

- 同一预警内，A1（某次新低）→ A2（其后的企稳）→ A3（其后的恢复观察）→ A4（其后的回踩）按时间顺序依次成立，记"证据链完整"。
- 报告时也分别列出只有部分环节成立的情形，不只看完整链。

## 3. 数据要求、无前视与异常处理

### 3.1 成交量单位与拆股

- 决策日 T 要比较的所有成交量，统一换算为"截至 T 已生效拆股"的股数单位：

  > V\_j(T) = V\_j(原始) × 所有除权日在 (j, T] 内的拆股比例之积

  1 拆 2 时，比例为 2，即除权前的成交量乘以 2。
- 只用除权日不晚于 T、且在除权日之前已经公告的拆股（红线 2 的澄清）。
- **分红不调整成交量**。
- 不同决策日的换算结果各自独立，不拼接成一条累计序列。
- **保留**原始成交量、换算因子与依据（公司行动记录），以及每个决策日当时形成的证据记录。之后重算只能新增版本，不覆盖原记录。
- 这一节的要求并入 D0a 复权规格，与价格复权同一套公司行动数据、同一套"决策日"口径。

### 3.2 异常与缺失

| 情形 | 处理 |
| --- | --- |
| 缺价日（没有日线） | 不是成交量日；不进入任何分母或分子 |
| 有日线但成交量缺失 | 成交量"未知"。不进入分母；当日 RVOL 未知；凡要用到它的 A1–A4 判断，相应环节记"未知" |
| 成交量为 0 | 是已知值。进入分母；单独计数报告；如果它使分母为 0，RVOL 未知 |
| 异常大值（拟议：大于此前 m 日中位数的 50 倍） | **不删除**，照常参与计算，并标记"异常量"，供逐日核对 |
| 半日市 | 当日 RVOL 照常计算，并标记"半日市"；当日不作为 A3 的单独依据：如果 A3 窗口只有半日市一日，记"未知" |
| 数据断点 | 新历史段重新积累分母；跨断点不比较 |
| 财报日等巨量日 | 没有财报日历数据，无法标记；不删除 |

缺失不填 0，不默认正常，不随意剔除。所有"未知"按环节、原因分别计数。

### 3.3 数据来源与核验

- 只用授权的探索数据，截至 2019-12-31，不触碰封存期。
- 只用一个数据源。D0b 之后为 Massive，不混用 Tiingo 的成交量。
- 记录该数据源成交量的统计范围（是否为合并成交量、是否包含盘前盘后）。查不到的记"未知"。
- **关键日期单独核对**：每只探索股中，A1、A3 成立日与异常量日，抽查与第二来源的差异（只在授权范围内）。不能用全样本差异中位数代替这一步。

### 3.4 证据只陈述，不回流

- A1–A4 只在 t 日收盘后、用截至 t 的数据形成，当日生效于诊断记录。
- 评价时可以用事后的谷底、F\_ref 等**评价层**信息来衡量证据好坏，但这些信息不得回流到 A1–A4 的计算（红线 2）。
- 措辞只用"下跌段量能较前一段减弱""恢复期成交量高于近期中位数"这类陈述，不用"见底""抛压耗尽""资金进场"。

## 4. 价格基线与增量对照

### 4.1 第一阶段：零干扰诊断

- **价格基线**：E6 中的 R0 与 12 组参考候选，规则、参数、事件全部不变。
- **量价模块**：一个独立的纯函数模块，输入为（单位换算后的日线，生命周期逐日记录与事件），输出为 A1–A4 的证据记录；**不写回生命周期状态**。
- **零干扰证明**：用 M0b 的全语义摘要，断言开启与关闭量价模块时，生命周期输出的摘要完全相同。
- **诊断对照**，同一批事件按证据分组比较：

| 比较 | 指标 |
| --- | --- |
| 新低：A1 成立 / 不成立 / 无比较 | 之后 Y 日内再创新低的比例；距最终谷底的跌幅（评价层）；到下一次企稳的天数 |
| 恢复观察：A3 成立 / 不成立 / 未知 | RECOVERY\_FAIL 与 RECOVERY\_REVOKED 的比例；到 RELEASE 的等待；同一周期内恢复观察的反复次数 |
| 恢复观察：A3 且 A4 / 其他 | 同上，加解除后的 p、p\_L |
| 完整证据链 / 部分 / 无 | 同上 |

- 同时报告覆盖率：每类证据出现在多少预警、多少证券上，以及"未知"与"无比较"的数量和原因。

### 4.2 第二阶段（另行提出，不在本草案批准范围内）

只有第一阶段在探索集上显示出稳定差异，才可能提出状态机改动。届时：
- 带量能与不带量能两个版本，在相同数据、相同价格规则、相同评价口径下比较，一次只改一个机制；
- 完整检查第 7 节列出的全部指标，包括 H1。改变解除条件也可能让候选在 F\_ref 之前解除，从而违反 H1；
- 成交量不得挡住原本成立的价格预警；
- 缺量时的处理写进规格。

### 4.3 报告指标（两个阶段都适用）

- S2、s、h\_tail、恢复后的等待；

## 6. 风险、副作用与不采用的条件

**风险与副作用**：
1. **样本小**：27 只探索股中，A1、A3 成立的次数可能很少，差异可能只是偶然。第一阶段只作描述，不作推断。
2. **缩量没有方向**：量缩可能是抛压减弱，也可能是无人交易。流动性差的股票上更难解读。
3. **定义灵活**：参数多，容易在探索集上调出好看的结果。预算上限与台账就是为此设的。
4. **数据问题集中在关键日**：拆股附近、半日市、异常量都可能恰好落在证据成立日。
5. **误导性安心**：如果以后把量能证据展示给用户，"恢复得到成交量支持"可能被理解为"安全了"。第一阶段只进内部报告，不进用户消息（第 7 节问题 6）。
6. **将来改解除**：可能让解除更晚，也可能更早、反复更多，还可能违反 H1。

**不采用或延期的条件**（拟议，在 T08c 冻结前判断）：
- 关键日核验不通过，或者成交量来源的统计范围无法确认；
- 证据覆盖率太低，例如 A1 有比较的新低少于全部新低的一定比例（比例待批准）；
- 第一阶段各分组之间看不出一致的差异，或者差异方向在不同证券上相反；
- 方案数已达上限，仍没有清楚的结论。

出现任一条，量价方向在本轮**延期**，记入台账，不为赶冻结而降低要求。

## 8. 需要与 ChatGPT 对齐的问题

1. 用引擎的"今日新低"与 L\_ep 作为低点的代理，在新低当日就形成证据，不需要右侧确认。这个做法是否充分表达了"二次下探"？代价是 t₂ 未必是最终的低点。
2. A1 只在两段之间有 ≥ r × ATR\_ep 的反弹时才比较。用这个条件把"连续下跌"与"二次下探"分开，是否合理？
3. A1 用"下跌日的 RVOL 中位数"比较两段，而不是两段的原始日均量。前者对单位与时间趋势更稳健，但会丢掉上涨日的信息。是否合适？
