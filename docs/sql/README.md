# SQL 脚本

探索阶段不使用数据库，本目录暂时没有脚本。库表设计见 [工程规格 v0.4 第 5 节](../develop_docs/11-工程规格_v0.4.md)。

## 命名规则

| 类型 | 文件名 | 说明 |
| --- | --- | --- |
| 基线 | `V0001__baseline.sql` | 首次建库建表的完整脚本 |
| 增量 | `YYYYMMDD_NN__说明.sql` | 例：`20261101_01__add_episode_index.sql`；NN 是当天序号 |

## 规则

1. 增量脚本一旦执行，不再修改；有错就写新的增量脚本修正。
2. 每个脚本开头注释写明：日期、目的、对应的开发文档章节、是否可重复执行。
3. 优先写可重复执行的语句（`IF NOT EXISTS`），不能重复执行的要明确标注。
4. 改表结构时，同步更新工程规格文档和变更记录。
5. 脚本里不写任何密码或连接串；连接信息只放在 `.env`（`MYSQL_VERIFY_URL`）。
