### 对照表

以同一结构组合、同一 N 的 V0 为基准。V2 及各单开关配对另见下文。

1. **逐日覆盖表** `coverage_daily_<套>.csv.gz`
   - 每行一个（证券, 交易日），只取双方都可计算的日子；字段为双方的 display、level、episode\_id。
   - 缺价、不可计算、数据中断的日子另存 `excluded_days.csv`。
   - 汇总四格：双方都有预警、只有 V0、只有新变体、都没有。按证券、按套给出。
2. **事件对照表** `event_compare_<套>.csv`
   - 每条记录可带多个标签（分号分隔），**不做互斥分类**。
   - **基准启动后的通知等待**：对每个 V0 START，记录新变体当日的状态（正常 / 关注 / 警戒 / 不可计算 / 缺价冻结 / 数据中断）。若无预警，记录随后 20、60 个有效交易日内新变体首次 START 的日期与等待日数，以及期间最低收盘相对 V0 启动收盘的跌幅。没有通知的标"20 / 60 日内无通知"，窗口不足、退市或数据中断的标"窗口不完整"。**不称为"延迟"。**
   - **反向**：对每个新变体 START 做同样的记录。
   - **加重**：对每个 V0 ESCALATE，记录新变体当日的状态（同上 6 种）。不是警戒的，记录随后 20、60 日内是否进入警戒，以及期间路径。
   - **解除**：对每个 V0 RELEASE 记录新变体当日的状态，反之亦然。只有当一次 V0 预警与一次新变体预警**互为唯一重叠**时，才计算解除日期差；其余标"多对多"。
3. **重叠映射表** `overlap_<套>.csv`：全部重叠关系，允许多对多。重叠按双方日末等级为关注或警戒的日子判断；解除日日末已为正常，不算重叠。
4. **单开关配对汇总** `pairs_summary.csv`
   - 配对：r2\_floor OFF / ON；long\_path X1 / X2；x1 8% / 10%；x2 15% / 20%（以上在 V1、V3、V4 内，其余设置相同）；release\_hyst（V1 与 V3 中设置相同的两套，以及 V0 与 V2）；rec\_scale（V3 与 V4 中设置相同的两套）；N 14 / 20（N14 组）。
   - 每对给出第 5 项的负担指标之差，以及逐日覆盖四格。
5. **专项清单**
   - **被过滤的 R2**：在 r2\_floor OFF / ON 配对中逐条列出。标签：(i) 当日 GAP 证据被过滤，但同日或随后由其他路径启动（记日期差）；(ii) OFF 中的 START 在 ON 中被取消（按通知等待记录，或"至观察终点无后续通知"）。另给出被过滤的 R2 **日数**，不把标签数量相加。
   - **被取消的加重**：V0 有、新变体没有的 ESCALATE，记当时的 D\_ep、DD\_ep 与此后 20、60 日的路径。
   - **L 路径带来的新增覆盖**：只有 L 成立的 START，记当时的 dd\_l、此后路径，以及 V0 当日状态。
   - **V1 中 L 启动后不涨即解除**：已知副作用（10 号第 1A.5 节），单列，不计入 L 路径的效果。
6. **通知负担** `burden.csv`
   - 每套每证券：每有效证券年的 START（首次 / 距上次解除 ≤ 20 个有效交易日的短期再启动）、ESCALATE、DOWNGRADE、RELEASE、RECOVERY\_OBS、RECOVERY\_REVOKED、RECOVERY\_FAIL 次数；
   - 占用率两种口径（合并证券日、跨证券中位数）；
   - 持续 ≥ 200 个交易日的预警个数与天数；
   - 解除后 20、60 个有效交易日内的最低收盘、相对解除收盘的跌幅、是否跌破所解除预警的 L\_ep（窗口不完整的单列）；
   - 未解除的预警（截尾或至观察终点）单列。
   - 统计期间与 15 号第 5 节相同（2010-01-01 至 2019-12-31）。
