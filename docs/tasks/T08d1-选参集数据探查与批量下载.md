## 1. 代码清单探查：`stock-risk probe-tickers`

**来源**：Tiingo 公开的代码清单文件 `supported_tickers.zip`（字段含 ticker、exchange、assetType、priceCurrency、startDate、endDate）。只下载这一个文件，**不下载任何价格**。

**封存处理**（必须在内存中完成，原始压缩包**不写盘**）：

- 丢弃 startDate 晚于 2019-12-31 的行，不计数、不输出；
- endDate 晚于 2019-12-31 或为空的，endDate 一律写为 2019-12-31，另加一列 `active_after_2019 = true`，**不保留真实结束日期**；
- 丢弃 endDate 早于 2008-01-02 的行。

**筛选与输出**：

- 只保留 exchange 为 NYSE 或 NASDAQ、assetType 为 Stock、priceCurrency 为 USD 的行。清单中出现的其他交易所取值（例如 NYSE MKT、NYSE ARCA）只计数，在回执中列出，由产品经理裁定是否纳入。
- 输出 `data/universe_probe/tickers_2008_2019.csv`（`data/` 不入库）：`ticker,exchange,start_date,end_date,active_after_2019`。
- 输出 `data/universe_probe/summary.json`：总数；按交易所、按 start\_date 年份、按"2019-12-31 之前结束 / 延续到 2019 年之后"的计数；同一 ticker 多行（代码复用）的个数及示例。
- **覆盖对照**（可选输入 `--check <csv>`，一列 `ticker`，可附 `from,to`）：逐个代码报告是否在清单中、清单区间是否覆盖所需区间。用于以后核对成分名单或其他候选名单。

**回执列出**：summary 的全部计数；exchange、assetType 的全部取值及计数；代码复用的例子 5 个。不列 2020 年以后的任何日期。

## 2. 批量下载：`stock-risk fetch-batch`

在现有 `fetch_raw_data` 用例上扩展，**复用**同一个 Tiingo 适配器、封存三道关、断点续传与 MANIFEST 机制，不另写一套。

**输入**：`--list <csv>`（列：`symbol,source_ticker,from,to`，`to` 不得晚于 2019-12-31）；`--out <目录>`，默认 `data/raw_selection/`，与探索集的 `data/raw/` 分开。

**额度保护**（参数可在命令行与 `.env` 设置，默认按免费档）：

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| `--per-hour` | 50 | 每小时请求上限，换算为请求间隔 |
| `--per-day` | 1000 | 每日请求上限，达到即正常退出 |
| `--unique-per-month` | 500 | 每个自然月新代码数上限，达到即正常退出 |
| `--max-symbols` | 不限 | 本次最多处理的代码数 |

- 额度计数持久化在 `<out>/_quota_state.json`（按 UTC 日期、月份记账）。
- 遇 429：按现有退避；连续 3 次 429 即保存进度并退出，退出码非 0，提示"额度已用尽，稍后再运行"。
- **可随时中断**（Ctrl+C）：已完成的代码已落盘，进度不丢；再次运行自动跳过已完成的代码。
- 每个代码一次请求取全区间，不按年拆分。

**状态与报告**：

- `_fetch_status.json` 记录每个代码：成功、无数据（404 / not found）、失败（原因）、跳过。
- 运行结束打印：本次完成数、累计完成数、剩余数、今日与本月已用额度、预计还需运行几次。**不打印密钥**，日志与异常信息中也不得出现密钥。
- 完成后可运行 `audit-raw --dir <out>` 做同样的审计。

**密钥**：只用 `.env` 中的 `TIINGO_API_KEY`（D-05 的密钥类型）。**不实现多密钥轮换**，不为绕过额度而支持多个免费账号。
