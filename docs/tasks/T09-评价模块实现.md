## 0. 背景与目标

项目已有生命周期引擎（10 号规格 v0.7.1 / v0.8 开关），能逐日给出每只股票"是否处于预警（关注 / 警戒）"。17 号评价协议规定了**如何评价**一套规则：先从价格构造"严重下跌事件"，再看各方法在这些事件上的预警表现（S1、S2、H1 等），最后按门槛与排序选参。目前这些评价只存在于 `docs/analysis/` 的一次性脚本中，口径也已过时。

本卡把 17 号的评价方法实现为 `domain` 层的纯函数，加上应用层的编排与命令行，在 27 只探索股上跑通一次，为后续的登记、选参与验证做准备。

**本卡不改任何生命周期规则，不改 17 号的任何规则。** 遇到 17 号与本卡、18 号夹具之间的矛盾或空白，停止并报告（第 9 节）。

## 3. 实现决定（产品经理裁定）

17 号写明的，照 17 号；17 号没写到的实现细节，按下列决定。编号在代码注释与回执中引用。

### 数值

- **D-01 十进制口径**：评价模块的全部比率（G、B、V、R 的恢复比例、S1、S1w、R\_E 的回升占比、跌幅、波动统计量、门槛比较等）一律用 `decimal`，上下文 `prec = 28`、`rounding = ROUND_HALF_EVEN`。表达式在该上下文中按书写顺序逐步计算，**最终结果**量化到 12 位小数（`Decimal("1e-12")`，ROUND\_HALF\_EVEN），再与阈值（同样以十进制给出，如 `Decimal("0.2")`）精确比较，不加容差。T/2 等阈值的派生量也在十进制中精确计算。
- **D-02 价格**：日线中的价格是六位小数量化后的 float（`numeric.quantize_price`）。转为十进制时用 `Decimal(f"{x:.6f}")`，并断言转换前后数值一致。价格与价格的比较（≥ 峰值、跌破低点、等于最低）用这个六位十进制值精确比较。
- **D-03 ATR₂₀（评价口径）**：用于 E\_atr 与 y\_atr 的 ATR₂₀ 在十进制中计算：TR 用量化后的复权价，C\_{t−1} 取同一历史段内上一条有效日线的收盘（与 `indicators.true_range` 规则相同）；ATR₂₀ = 最近 20 个 TR 之和 ÷ 20（需要 21 条有效日线），**本身不量化**，参与比率计算后再按 D-01 量化。波动统计量的 ATR₂₀ / 收盘同此。
- **D-04 F\_ref 的数值口径**：F\_ref 判定沿用 T06 V0 回归时的引擎口径（17 号第 4 节）：调用 `domain/lifecycle/start_paths.evaluate_start`，即 float 与 `numeric.py` 的 ε 容差，**不用** D-01。见 D-12。

### 日、掩码与历史段

- **D-05 "日"**：除另有说明，"日"一律指有效交易日（有日线的交易日）。窗口长度、n、q、w、Y\_max、Y\_cap、Q、Q\_L、"j − 62"、"e\_prev + 63"都按有效日计数；缺价日不进窗口、不计天数。窗口内的"不可评估日"指窗口中不在掩码内的**有效日**（例如 DATA\_BREAK 之后新历史段的预热日）。
- **D-06 历史段**：按 G 切分，与引擎相同（`history_segments.split_segments`；连续缺价达到 G + 1 日即断点，断点之后第一条日线开始新历史段）。G 必须与被评价方法回放时的 G 相同，由调用方传入。
- **D-07 公共可评估掩码**：第 k 日可评估 ⇔ 当日有日线，且本历史段内截至当日（含）的有效日线数 ≥ M\_mask。M\_mask = W + max(N)，由调用方按被比较方法的集合传入（现网格为 63 + 20 = 83；B1 需要 63、B2 需要 50，都不超过 83）。缺价日、断段中的日子一律不可评估。

### 事件状态机（17 号第 2.2 节的补充）

- **D-08 处理顺序**：搜索、进行中、待确认三种状态，每日按 17 号第 2.2 节的顺序判断。进行中：先 n 加 1 并更新 L、ℓ、M，再依次判断 (a) 回到峰值、(c) n = 252、安静计数；待确认：先 n、w 加 1，再依次判断并入、回到峰值、n = 252、w = 20。开始日（n = 1）不判断任何结束条件。并入当日 q = 0，L、ℓ、M 从并入日重算；并入当日若 n = 252，以 (c) 结束（e = 当日）。
- **D-09 受限窗口**：H\_j 取本历史段内、含 j 的最近 63 个有效日中，日序号 ≥ e\_prev 的那些日子的最高收盘（并列取最近）。e\_prev 在本历史段之外（或没有上一事件）时不起作用。可开始的最早日 = max(本历史段掩码成立的第一日, e\_prev 的次日)。
- **D-10 回放**：一个事件确认后，搜索从它的结束日 e 的次日起重新逐日判断（包括已经过去的 (e, 确认日] 区间），连续识别后继事件，直到数据终点。实现可以用"日序号指针回退"完成；这只是事后标签的构造方式。
- **D-11 截尾与不可评估**（同一事件可以并存多项，全部记录）：
  - **历史断点**：事件处于进行中或待确认时出现断点日（连续缺价第 G + 1 日），事件记截尾 `DATA_BREAK`，不再确认；事件链重置，e\_prev 置空；搜索在新历史段掩码成立后才恢复。
  - **缺价**：[p, 确认日] 内有缺价日（m ≤ G）的，记截尾 `MISSING`；状态机照常越过缺价日继续运行到确认，以便确定后继事件的搜索起点。事件在数据终点时仍未确认（右端截尾，包括进行中与待确认）的，若 [p, 数据终点] 内有缺价日（包括数据终点前的尾部缺价，m ≤ G），记截尾 `MISSING`。断点截尾（`DATA_BREAK`）的事件不另记 `MISSING`，因为构成断点的连续缺价本身就是断点。（T09-E1R R2）
  - **右端截尾**：数据终点时事件仍在进行中或待确认，记截尾 `RIGHT_<原因>`（待确认时被截尾的，保留暂定结束日 e 与原因 b；进行中时被截尾的，e 与原因为空），原因取序列的终止原因：`DATA_END`（数据终点）、`DELISTED`（退市或被收购）、`REQUIRED_END`（必需区间终点）、`PERIOD_END`（期间终点 2019-12-31）。暂定谷底 k\* = [p, 最后一个有效日] 内最低收盘的最早一日。
  - **依赖未决**：数据终点时事件处于待确认的，另记依赖未决区间 (e, 数据终点] 及其中的有效日数；该区间不建立后继事件。
  - **不可评估**：[p, 报告谷底]（右端截尾时为 [p, k\*]）内有不在掩码内的日子：其中有预热日（有日线但段内计数 < M\_mask）的记 `WARMUP`；有缺价日的记 `MISSING`。
  - **主口径**：已确认、没有任何截尾、没有任何不可评估原因的事件。
  - **前缀完整**（暂定谷底口径与 H1 用）：只有右端截尾一项，且 [p, k\*] 内每一日都在掩码内。
- **D-12 报告谷底**：[p, e] 内收盘等于最低收盘的最早一日。恢复锚 ℓ\_j 是 [p, j] 内收盘等于 L\_j 的**最近**一日。
- **D-13 标记**：以 (c) 结束的标 `cap`；待确认期内回到峰值而确认的标 `peak_in_confirm`；待确认期在 n = 252 处确认的标 `confirm_cut_by_cap`；上一事件以 (c) 结束、且本事件 s 与上一事件 e 相差不超过 63 个有效日的，标"上限延续"。
- **D-14 可确定日期**：事件标签的可确定日 = 本事件与其全部前序事件（同一证券、同一事件集、已确认者）的确认日中最晚者。只有已确认的事件才有标签可确定日：右端截尾与断点截尾的事件没有；缺价截尾但已确认的事件有（它不进主口径），它的确认日也计入后继事件的标签可确定日。各指标的可确定日按 17 号第 2.2 节公式；窗口终点用**目标窗口**的终点（例如 S2 为 Ω\* 的终点），即使数据在此之前结束。

### 方法的状态与事件结果

- **D-15 日末状态**：方法在第 k 日"在警" ⇔ 当日处理后存在进行中的预警（等级为关注或警戒）。以 RELEASE 或 DATA\_BREAK 终止预警的当日不在警。引擎方法从 `DailyRecord.level` 取（`level is not None` 即在警，`level == ALERT` 即在警戒），episode\_id 从 `DailyRecord.episode_id` 取。缺价日的状态照引擎冻结值保存，但缺价日不可评估。
- **D-16 延续到谷底的预警段**：从第 k − 1 日（k 之前最近的有效日）向前，取连续有效日中日末在警、且 episode\_id 相同的最长一段，首日为 f₀。缺价日跳过（不打断，也不计入）。"episode\_id 相同"是 17 号第 9.1 节"连续在警属于同一 episode\_id"的落实：引擎方法与基线每日最多一次等级转移，解除日不在警，所以不会出现"连续在警而 episode\_id 改变"，这一条对它们不改变结果；若出现，按断开处理，并在诊断计数中记录。
- **D-17 S1w**：f\_w 取该预警段 [f₀, k − 1] 内第一个日末等级为警戒的日子；f\_w < p 记 0；p ≤ f\_w < k 记 (C\_p − C\_{f\_w}) / (C\_p − C\_k)；段内从未警戒、或没有预警段的，记 1。
- **D-18 首次提醒指标**：p 之前最近的有效日日末在警的，记"峰值前已在警"；否则首次 START 日 = [p, k) 内第一个"当日在警、而前一有效日不在警"的日子，报告该日及其跌幅 1 − C/C\_p。另报：日末不在警的可评估日数，统计区间为 (首次 START 日, k − 1]（不含首次 START 日）；峰值前已在警的，区间为 [p, k − 1]（含 p）。
- **D-19 U 的两种情形**：p 之前最近的有效日至 k − 1 之间有任何一日在警的，记"提醒后谷底前解除"（RELEASED\_BEFORE\_TROUGH）；否则记"从未提醒"（NEVER）。
- **D-20 谷底日**：另报第 k 日日末是否在警、第 k 日是否发生 RELEASE。

### H1

- **D-21 F\_ref**：对 [p, k)（右端截尾时 [p, k\*)）内、在掩码内的每一日 j 按顺序检查；第一个使"旧规则启动条件成立"的 j 即 F\_ref。启动条件的判定：调用 `evaluate_start(src, j, last_release=p, params=R0)`，返回的等级不为空即成立；其中 `src` 是 p 所在历史段的 `ComputedIndicators`，`R0` 为网格序号 385 的候选（N = 20、k₁ = 2、atr\_basis = PEAK，即 A\_start 取峰值日的 ATR₂₀）、`EXPLORATION_ASSUMPTIONS`、默认容差、V0 开关（全部关闭）。D\_T 恰等于 k₁ 时按 ε 判为成立（夹具 B14、B21、B33 都落在这一边界上）。`last_release = p` 正好使 S 路径的回看窗口为 [max(p, j − 62), j]；跳空路径照常。若 `evaluate_start` 在掩码内的日子抛错，停止并报告。
- **D-22 H1 判定**：主口径事件与前缀完整的右端截尾事件（F\_ref 落在 [p, k\*) 内）计入判定，结果为 OK 或 VIOLATION（F\_ref 当日日末不在警）；F\_ref 不存在的记 NOT\_JUDGED（主口径）或 UNKNOWN（右端截尾）；其余（缺价截尾、断点截尾、依赖未决、不可评估）一律 UNKNOWN。三个事件集（E\_pct、E\_atr、E\_pct10）都判定。

### 窗口指标

- **D-23 R\_E**：在 (k, min(k + Y\_max, 下一事件的峰值日)] 内（有效日序号运算，含下一事件的峰值日）找第一个回升占比 ≥ ρ 的日子。找到即 FOUND；搜索范围全部在数据内而没有找到的，记 NOT\_RECOVERED；搜索范围超出数据终点而没有找到的，记 INSUFFICIENT\_OBSERVATION。"下一事件"指同一证券、同一事件集按开始日排序的下一个事件（无论是否截尾、是否在入选期间）。
- **D-24 S2 窗口分类**：目标终点 t\* = R\_E + Y\_cap − 1；下一事件界 b = 下一事件峰值日 − 1（没有下一事件时为无穷）；观察终点 = min(t\*, b, 数据终点)。
  - 观察终点 = t\*：完整，可评估日 ≥ n\_min 为 A 类，否则 B 类；
  - 否则若数据终点 ≤ b：C 类（与下一事件界同日时也记 C，即"数据不足"）；补足终点 = min(t\*, b)，未观察的日数 = 补足长度 − 已观察长度，记为在警；
  - 否则：D 类（被下一事件截短）。窗口为空（R\_E > b）即"截空"，不纳入。
  - 主口径 S2：观察窗口内可评估日 ≥ n\_min 即纳入（A、C、D 类都可能），值 = 在警的可评估日 ÷ 可评估日。
  - 补足口径 S2⁺ =（在警的可评估日 + 窗口内不可评估日 + 未观察日）÷ 补足长度；补足长度 ≥ n\_min 才纳入。
  - s 的主口径：A 类（完整且可评估日 ≥ n\_min）；补足口径：补足终点等于 t\* 的 A、B、C 类。
  - **跨越 DATA\_BREAK**：S2 与 h 的窗口不因历史断点截断，按有效日继续计数；断点之后新历史段中不在掩码内的有效日（预热日）是窗口内的不可评估日（夹具 B35、B36）。只有解除与恢复观察的窗口不跨越断点（D-26，17 号第 3C 节）。
- **D-25 h 窗口**：只对 R\_E 不是 FOUND 的主口径事件计算。目标终点 t\_h = min(k + Y\_max, 下一事件峰值日 − 1)；t\_h < k 为截空（不计算，计数报告）。数据覆盖到 t\_h 的为完整（A / B 类）；否则为 C 类，补足到 t\_h（下一事件未知时 t\_h = k + Y\_max）。h 没有 D 类：下一事件的界已是目标的一部分。主口径 h：完整、非空、可评估日 ≥ n\_min，且 R\_E 为 NOT\_RECOVERED。补足口径 h⁺：A、B、C 类，补足长度 ≥ n\_min 即纳入，R\_E 为 NOT\_RECOVERED 或 INSUFFICIENT\_OBSERVATION。
- **D-26 解除与恢复观察的窗口**：RELEASE 日 r 之后（不含 r）的 Q（或 Q\_L）个有效日。完整 ⇔ 这些日子都在数据内（含必需区间终点、期间终点），且都与 r 在同一历史段（不跨越 DATA\_BREAK）。三条不利条件按 17 号第 3C 节，① ② 按 D-01，③ 为价格精确比较（C < L\_ep，L\_ep 取被解除预警在 r 日的 L\_ep）。A\_r = ATR₂₀(r)（D-03）。对每个窗口另报：窗口内最大跌幅（比例与 ATR 倍数）、是否跌破 L\_ep、首个不利日；y\_pct、y\_atr 未给定时只报告这些量，不判不利。恢复观察（RECOVERY\_OBS 日 o）同样处理，基准为 C\_o 与该预警当日的 L\_ep，另报窗口内是否发生 RECOVERY\_FAIL。

### 入选期间、占用率与频次

- **D-27 入选期间**：以若干 [起日, 止日) 区间给出（探索集为 [2010-01-01, 2020-01-01) 与观察区间的交集）。事件按峰值日、RELEASE 与 RECOVERY\_OBS 按信号日判断是否纳入；窗口不因退出入选而截断。占用率 = 入选期间内、掩码内日子中日末在警的比例；F 与通知负担 = 同一批日子上的事件数 × 252 ÷ 日数（"每证券年"按 252 个可评估日折算）。日数为 0 的证券不进跨证券中位数，个数报告。

### 基线与分组

- **D-28 基线**：
  - **B1**：每个可评估日计算 dd = 1 − C / P\_max（P\_max 为本历史段、last\_release 当日及之后、含当日的最近 63 个有效日的最高收盘，并列取最近）。不在警：dd ≥ 0.20 启动为警戒，否则 dd ≥ 0.10 启动为关注；关注：dd ≥ 0.20 升为警戒、计数清零；dd < 0.10 计数加 1，达到 d 即 RELEASE（last\_release = 当日）；否则计数清零。警戒：dd < 0.20 计数加 1，达到 d 即降为关注、计数清零；否则计数清零。L\_ep = 启动当日所用 P\_max 的日期起至今日的最低收盘。
  - **B2**：SMA50 = 本历史段最近 50 个有效日收盘之和 ÷ 50（十进制，量化到 12 位）。不在警：C < SMA50 启动为关注；在警：C > SMA50 计数加 1，达到 d 即 RELEASE；否则计数清零。L\_ep = 启动日起至今日的最低收盘。
  - 两者共同：掩码成立前不启动；缺价日冻结全部状态（等级、计数、L\_ep 都不变）；断点日以 DATA\_BREAK 终止预警（不发 RELEASE），清空 last\_release；比较按 D-01、D-02 精确进行。每日最多一次等级转移。
  - **B3**：先求 [p, k) 内各有效日收盘的平均值 C̄（十进制，不量化），再算 E[S1] = (C\_p − C̄) ÷ (C\_p − C\_k)，最终结果量化到 12 位。不参与 S2。
- **D-29 波动分组**：证券统计量 = 开发期全部可评估日 ATR₂₀ / 收盘（各日按 D-01 量化）的中位数（偶数个取中间两个的平均，量化到 12 位）。分位数用 Hyndman–Fan 第 7 型：h = (n − 1) × p，结果 = x\_⌊h⌋ + (h − ⌊h⌋)(x\_⌊h⌋+1 − x\_⌊h⌋)，十进制计算，量化到 12 位；p = 1/3、2/3 在十进制中按 `Decimal(1) / Decimal(3)` 计算。归属：≤ b₁ 低组，(b₁, b₂] 中组，> b₂ 高组。验证期新证券按 17 号第 3.1 节（前 252 个可评估日；63–251 个用全部；不足 63 个为未归组）。
- **D-30 季度筛选**（17 号第 1.1 节的纯函数部分）：筛选日 D 的信息截至 D 的前一个市场交易日。资格：① 证券类别合格（由调用方给出布尔值）；② 最后一条有效日线与 D 的市场日序号之差 ≤ 5；③ 截至前一交易日的 63 个市场交易日中，有效日线 ≥ 57 条；④ 本历史段截至前一交易日的有效日线 ≥ M\_mask；⑤ 最近 63 个有效日的原始收盘中位数 ≥ 5；⑥ 同一批日子的日成交额（原始收盘 × 原始成交量）中位数 > 0。代表股类与排名按 17 号第 1.1 节的处理顺序；"首次出现"指发行人首次有股类通过资格，不要求进入前 N\_u；排名与并列都按"成交额中位数降序、稳定标识字典序升序"。

### 探索临时值

- **D-31 探索临时值**（17 号"拟定"值，只用于本卡的探索集运行与夹具；登记时由发起人批准）：X\_pct = 0.20，X\_pct10 = 0.10，ρ\_end = 0.5，W\_Q = 20，ρ = 0.5，Y\_max = 252，Y\_cap = 60，Q = 20，Q\_L = 60，n\_min = 10，M\_mask = 83。E\_atr 的 X 在探索集运行中对 {6, 8, 10, 12} 都计算，并按 17 号第 7 节的校准规则报告建议值（D25），不自行选定。这些值集中放在一个"拟定值"常量对象中，标注"拟定，待 SR-M1′ 批准"，并在 00 号变更记录中写明。

- `domain/evaluation` 只依赖标准库与 `domain` 内的其他模块（`numeric`、`calendar`、`market_data`、`lifecycle` 的公共函数与模型）。不做 I/O，不读时钟，不读配置。

- 领域对象用 `@dataclass(frozen=True, slots=True)`；全部函数带类型标注。

### 4.2 核心数据结构（字段为最低要求，可增加）

- **EvalSeries**（每只证券一份）：交易日历上的逐日序列（观察区间内），每日为一条 `DailyBar` 或缺价；G；M\_mask；终止原因（DATA\_END / DELISTED / REQUIRED\_END / PERIOD\_END）。派生：历史段编号、段内有效日计数、断点日、有效日列表与序号、掩码、十进制收盘、十进制 ATR₂₀。
- **EventSetSpec**：kind（PCT / ATR）、阈值（Decimal）、名称（E\_pct、E\_atr\_X、E\_pct10）。
- **SevereEvent**：s、p、C\_p、e、reason（a / b / c）、confirm、flags、report\_trough、k\_star、censor（集合）、unevaluable（集合）、dependency\_pending、label\_determinable、cap\_continuation、merges、is\_main、is\_prefix\_complete；A\_s（E\_atr）。
- **EventChain**：一只证券、一个事件集的全部事件（按 s 排序），以及依赖未决区间与各类计数。
- **MethodSeries**：方法名；逐日（与 EvalSeries 同一日历）的等级（None / WATCH / ALERT）与 episode\_id；事件列表（类型、日、episode\_id、RELEASE 与 RECOVERY\_OBS 时该预警的 L\_ep、START 与 ESCALATE 等）；预警终止原因（RELEASE / DATA\_BREAK / 截尾）。提供 `from_run_result(run_result)`（引擎方法）与基线的构造。
- **EventOutcome**、**H1Result**、**S2Window**、**HWindow**、**ReleaseWindow**、**SecurityMethodStats**：字段按第 7 节输出列。
- **Membership**：[起日, 止日) 区间列表。

### 4.3 接口要点

- 函数以"证券 × 方法"为单位纯计算，便于以后多进程并行；汇总在 `aggregate.py`。
- 事件构造只依赖价格，对所有方法共用一份。
- 任何"日"在函数间以 `date` 传递；内部可以用有效日序号，但对外字段一律是日期。
- 夹具 JSON 用日序号；测试辅助函数负责日序号与日期的互换（第 6 节）。

### E5 重采样

- 实现 `resampling.py`，严格按以下程序（夹具 E17 依赖这个程序逐位复现）：
  1. `rng = random.Random(seed)`。
  2. 每次重复：先抽证券 `[rng.randrange(I) for _ in range(I)]`；再抽块：L\_b = 1 时 `[rng.randrange(J) for _ in range(J)]`；L\_b > 1 时先抽起点 `[rng.randrange(J − L_b + 1) for _ in range(ceil(J / L_b))]`，每个起点展开为 L\_b 个相邻块，按顺序拼接后截取前 J 个。
  3. w\_i 为证券 i 被抽中的次数，v\_b 为块 b 被抽中的次数；格 (i, b) 的权重 w\_i × v\_b。
  4. 事件加权均值 = Σ 权重 × 值 ÷ Σ 权重（十进制）；分母为 0 的重复对该统计量无效；基线或候选（参与本次比较的方法）的均值分母为 0，该次重复对这一比较无效。共同的重采样权重不变：各方法仍使用同一组抽取。（2026-10-17 按 T09-E5F 修订；原文为"任一方法无效即该次重复无效"。）
  5. Δ\* = 基线均值 − 候选均值（同一组权重）；p = (1 + #{有效重复中 Δ\* ≤ 0}) ÷ (B\_v + 1)；B\_v < 0.99 B 时方法判为不适用。
  6. 单侧 95% 下界取 Δ\* 的第 5 百分位（第 7 型分位数）；Holm 校正按标准程序。
  7. 块划分：按期间的市场交易日历，自期内首个交易日起每 63 个交易日为一块，末尾不足 63 日的并入前一块。事件按（证券，峰值日所在块）归组；RELEASE、RECOVERY\_OBS 按（证券，信号日所在块）。
- 测试：E17（逐次的 w、v、各方法均值、Δ\*，以及有效重复数与 p，L\_b = 1 与 2 两种）；另加 Holm 校正与 B\_v 阈值的单元测试。
- 验收：全部通过。
