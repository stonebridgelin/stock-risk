## 1. 问题与根源

`domain/evaluation/resampling.py` 中：
- `bootstrap` 把"全部方法都有均值"记为 `Replicate.valid`；
- `improvement_test` 用这个全局标志判断每次重复是否有效。

结果是，一个与本次比较无关的方法缺少数据，会使基线与候选的比较失效。

**复现**（ChatGPT R3）：
- 设定：一个证券、一个块，基线得分 0.5，候选得分 0.4，B = 100。
  - 只传基线与候选：B\_v = 100，适用，p = 0.009900990099。
  - 再加入一个值为空的无关方法：B\_v = 0，不适用，p 为空。
- 两种情况下，基线与候选的均值始终是 0.5 与 0.4。

**根源在任务卡**：T09 卡 E5 第 4 步写的是"任一方法无效即该次重复无效"。本意是"参与本次比较的任一方法无效"，执行者照字面实现了。

## 2. 裁定与改法

1. **规格修订**：T09 卡 E5 第 4 步改为："基线或候选（参与本次比较的方法）的均值分母为 0，该次重复对这一比较无效。"
   - 共同的重采样权重不变：各方法仍使用同一组抽取。
   - 卡上加注"2026-10-17 按 T09-E5F 修订"。
2. **代码**：
   - `improvement_test` 只看本次比较的基线与候选均值是否为空，不再使用 `Replicate.valid`。
   - **配对有效重复**：基线与候选的均值都不为空的重复。B\_v、Δ\* 序列中的非空项、p、适用性与单侧 95% 下界（`lower95`）**全部只用这同一组重复**计算，任何一处都不得另读 `Replicate.valid`。
   - Δ\* 序列仍按重复的原顺序输出，配对无效的重复记为空，长度等于 B。
   - `Replicate.valid` 保留，作为"全部方法都有值"的诊断字段，但**不得控制任何一对方法的检验**。
   - 核对 `resampling.py` 以及评价模块中其他使用 `Replicate.valid` 的地方，凡是用它判断某一对比较的，都按同样规则修改，并在回执中逐处列出。
3. **不变的内容**：抽取程序（第 1–3 步）、p 的公式、B\_v 阈值、下界与 Holm 校正，都不变。E5-01 的裁定也不变。

## 2A. C1-01 裁定：不完整窗口没有已知不利时记"未知"

**问题**：T09-C1 卡 C-05 要求，窗口不完整、已观察部分没有已知成立的条件时，"是否不利"记为未知。但夹具 B41e、B41f 对这种情形的期望是"否"。执行者按停止条件保留了原行为，做法正确。

**裁定：采用"未知"。**
- **依据**：没有观察完整的窗口，不能断言"不利没有发生"；记为"否"等于把未知当作通过，违反发起人的红线"未知不能记为通过"。
- **对指标的影响**（产品经理已核对代码）：
  - 主口径 p、p\_L 只用完整窗口，不受影响；
  - 补足口径由调用方把不完整窗口一律记为不利（`aggregate.adverse_rate` 的说明），也不受影响。

  所以，**按协议正确组装输入时**，C1-01 的改动不改变这些比率。这里的前提是两步组装都做对：主口径先筛出完整窗口；补足口径把不完整窗口记为不利。`aggregate.adverse_rate` 只接收布尔值，不负责这两步；E6 的编排尚未实现，所以要用下面的测试，从窗口结果出发验证整条组装链（EF-05）。

## 3. 测试

1. **E17 不变**：夹具 E17 两种情形（L\_b = 1、2）的全部期望值保持不变，测试照常通过。
2. **ChatGPT 的复现例**（期望由产品经理推导）：
   - 设定：一个证券、一个块，基线得分 0.5，候选得分 0.4，B = 100，种子任取并在测试中固定。
   - 推导：只有一个格，每次重复的权重都是 1 × 1，所以每次 Δ\* = 0.5 − 0.4 = 0.1 > 0，没有 Δ\* ≤ 0 的重复。
   - 期望：
     - B\_v = 100；适用；
     - p = (1 + 0) ÷ (100 + 1) = 0.009900990099（12 位小数）；
     - 每次 Δ\* = 0.100000000000。
   - 加入一个值全为空的无关方法后，上述结果**完全相同**。
3. **永久回归（不变性）**：对同一组观测与同一种子，以下三种操作都不得改变既有比较的 Δ\* 序列、B\_v、p 与适用性：
   - 加入无关方法（有值的、全为空的、部分为空的各一种）；
   - 删除无关方法；
   - 改变方法的传入顺序。

   断言的内容包括 Δ\* 序列、B\_v、p、适用性与 `lower95`，逐位相同。

   做两组基准：
   - **甲**：E17 的两方法情形。
   - **乙（G-EF-02、RV-01）：候选在部分重复中为空**。固定夹具：
     - I = 2，J = 1，L\_b = 1，B = 100，seed = 7；两个证券都归块 0。
     - 证券 0：基线 0.5，候选 0.4，无关方法为空。
     - 证券 1：基线 0.5，候选为空，无关方法 0.6。
     - **独立核算**（ChatGPT 用独立程序按"先抽证券、再抽块"复算；产品经理另写循环，按 T09 卡 E5 第 2 步的抽取程序、Python 3.13、`random.Random(7)` 复核，结果相同；都不调用待测实现）：

       | 抽取情况 | 次数 |
       | --- | ---: |
       | 两次都抽证券 0 | 35 |
       | 两个证券各抽一次 | 44 |
       | 两次都抽证券 1 | 21 |

     - 期望：
       - 配对有效重复数 B\_v = 79（有证券 0 被抽中的重复）；`Replicate.valid` 为真的只有 44 次；
       - 每个有效 Δ\* = 0.100000000000；两次都抽到证券 1 的 21 次，Δ\* 为空；
       - p = 1 ÷ 80 = 0.012500000000；
       - `lower95` = 0.100000000000；
       - 79 < 99，**不适用**；p 仍照常报告。
     - 加入、删除这个无关方法以及改变传入顺序，上述各项与逐次 Δ\* 序列都不变。

4. **诊断字段**：断言 `Replicate.valid` 在有无关方法为空时为 False，但不影响上述比较。
