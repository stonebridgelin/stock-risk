| 项 | 实现 |
| --- | --- |
| 设置 | `MASSIVE_ADVANCED_BASE_URL`，进入 `Settings.massive_advanced_base_url`；`.env.example` 加一行空值与说明 |
| 取值 | `bootstrap.massive_paid_base_url`：未设置或空白取 `https://api.massive.com`；只允许它与 `https://relaynex.vip`；其他值（包括 `http://`、末尾带 `/`、不带协议）在命令入口报错停止。适配器构造时再检查一次 |
| 生效范围 | 只对付费档命令生效：`probe-massive-paid` 与新命令 `verify-massive-relay`。免费档的 `probe-massive`（含 `--followup`）仍只连 `api.massive.com`，只用 `MASSIVE_API_KEY` |
| 密钥不交叉 | 一个适配器实例只连一个主机；付费档实例用 `MASSIVE_ADVANCED_API_KEY` 与配置的主机，免费档实例用 `MASSIVE_API_KEY` 与官方主机；一次运行只建一个实例 |
| 认证 | 仍用请求头 `Authorization: Bearer <key>`，密钥不进 URL |
| 翻页地址 | `next_url` 只接受与本实例主机相同的 https 地址，并去掉其中的 apiKey 参数；主机不同时报错停止，不向另一个主机发请求 |
| 来源记录 | 付费档的每个 CSV 末尾加 `source_host` 列；`_progress.json` 与 `summary.json` 带 `source_host` 键 |
| 不混写 | 付费档目录（含 `verify/` 子目录）中已有其他主机的记录时，在命令入口拒绝运行 |

**说明**：T08d-2c 之前写出的文件没有 `source_host`，不视为任何主机的记录。例如：

- 改名保存的 401 进度；
- 上次的 `samples.csv`、`summary.json`。

否则现有目录会被判为"官方主机"，中转服务无法在同一目录运行。下一次付费档运行会覆盖这些旧的汇总文件。

## 待确认（执行者的处理，不作为决定）

1. **成交量的第 95 百分位**：卡上写"成交量相对差的中位数与 95% 分位"，没有写明分位针对的是带符号的值还是绝对值。我的处理：中位数取带符号的相对差，第 95 百分位取相对差的**绝对值**。
2. **第 3.2 节比例的分母**：
   - 只在一边出现的比例 = (只在官方 + 只在中转) ÷ 官方快照条数；
   - 字段不同的比例 = 有字段不同的行数 ÷ 官方快照条数。

   两边的条数都另行报告。
3. **行的对应方式**：按（查询，代码，同一查询内的出现序号）对应。同一查询中同一代码出现多次时，按出现顺序配对。
4. **代码沿用 `symbol`**：中转服务按当时的代码请求，例如 VRX、FB、SHLD，不换用 `source_candidates` 中的其他代码。查不到的照实记为 not\_found。
