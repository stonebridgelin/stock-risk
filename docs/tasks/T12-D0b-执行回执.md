**认定规则**（`application/d0b_inventory.determine_identity`）：

- **依据**：本地中转服务核验文件中，中转服务按研究样本代码取到的行数与起止日。
- **规则 ①**：中转服务有数据，且末日与 Tiingo 相同，或由上市期间解释 → 整段用研究样本代码。
- **规则 ②**：中转服务末日早于 Tiingo、又不能由上市期间解释 → 后一段用 `source_candidates` 中的下一个代码，从下一个 XNYS 交易日起。VRX 属于这种情况；BHC 段本地没有核验文件，P3 会核验它。
- **规则 ③**：中转服务 0 行 → 只有在源代码映射中有带裁定编号的登记时才采用，否则停止。SONY 属于这种情况，采用 PM-D0b-01。

**说明**：
- 范围按卡上的定义取 max(2008-01-01, 上市起)。`listing_periods.csv` 中没有登记上市起日的证券，请求范围都从 2008-01-01 起。FB、TSLA、TWTR 在上市前本来就没有日线，这不是缺口。
- 核验文件只覆盖 2010–2019 年，2008–2009 年的代码选择没有本地核验。P3 下载后按日历核对首日，并单独报告。
