### 测试要点

- **ChatGPT 复现例**：一个证券、一个块，种子固定为 20261017，B = 100。
  - 结果：B\_v = 100，适用，p = 0.009900990099，每次 Δ\* = 0.100000000000。
  - 加入值全为空的无关方法后，Δ\* 序列、B\_v、p、适用性、`lower95` 逐位相同。
  - 此时 `Replicate.valid` 全部为假。
- **不变性，甲（E17）**：对每种 L\_b，测了以下六种变化，Δ\* 序列、B\_v、p、适用性、`lower95` 逐位相同：
  - 加入无关方法：有值、全为空、部分为空各一种；
  - 改变传入顺序，两种；
  - 删除无关方法：观测中有值，但不参与。
- **不变性，乙**：固定夹具为 I = 2，J = 1，L\_b = 1，B = 100，seed = 7。
  - **独立复算**：测试中另写循环，按 T09 卡 E5 第 2 步、`random.Random(7)` 复算抽取，不调用待测实现，得两次都抽证券 0 的 35 次、各一次的 44 次、两次都抽证券 1 的 21 次，与卡上一致。
  - **结果与期望一致**：
    - 配对有效重复 B\_v = 79，`Replicate.valid` 为真的 44 次；
    - 21 次两次都抽到证券 1 的重复 Δ\* 为空，位置与独立复算逐一对应；其余 Δ\* = 0.100000000000；
    - p = 0.012500000000，`lower95` = 0.100000000000，不适用（79 < 99），p 照常报告。
  - 加入、删除无关方法与改变传入顺序，以上各项都不变。
- **组装链**：映射规则按卡上第 2A 节的表写死。
  - "修改后"分支用修改后代码对 B41e、B41f 的实际输出，并断言不完整窗口的 `adverse` 都不为假、没有"完整而未知"的窗口。
  - "历史"分支把三处不完整窗口改回夹具 v1.3 的"否"，只在这一分支允许这种状态；用修改后分支的约束检查历史输入时，测试断言会失败（没有放宽）。
  - 两个分支的 p、p\_L、p⁺、p\_L⁺ 都等于 0、空、0.5、1。
