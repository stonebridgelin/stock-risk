## 1. 裁定

E3-01 是产品经理的夹具生成错误。参照实现中，W1 的定义是"每日成交量 700，第 100 日改为 1000000"。写 JSON 时只写出了覆盖值，漏掉了基础值。E3 执行者按 700 推出的输入是正确的。

**JSON 格式**：`raw_volume` 允许两种写法。

| 写法 | 含义 |
| --- | --- |
| 整数 | 每个有日线的日子成交量都相同 |
| 对象 | 键 `"default"` 是其余日子的成交量；其他键是日序号，值是那一日的成交量 |
