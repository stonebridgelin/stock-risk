## 维护规则

1. **代码与文档同步。** 任何改变行为、结构、数据格式或参数的提交，必须在同一次提交中更新相关文档，并在 [00-变更记录](00-变更记录.md) 加一条。
2. **修订标注来源。** 探索中发现的问题，修订时标注"探索中发现"并写明数据依据（代码、日期、图表文件）。
3. **业务数值不由代码作者决定。** 文档里所有待批准的数值标注"待批准"。没有批准的规则不生效，代码中也不得硬编码成默认值，只能作为探索期的临时值，并在变更记录中写明。
4. **延期功能标为"移出第一版，后续重审"**，不得写成"已解决"。
5. **SQL 放在 [`docs/sql/`](../sql/README.md)**，命名规则见该目录的 README。
