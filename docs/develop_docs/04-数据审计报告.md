## 4. 对后续回放的影响

1. **VRX**：回放使用拼接后的文件，2018-07 不再被误判为数据结束；拼接点无价格跳变、无复权系数变化。
2. **SHLD、WFT、SMH**：回放必须按 `config/listing_periods.csv` 截取（domain 已有 `clip_history_to_listing`）。不截取会把场外报价和另一证券的历史混进来：SHLD 多 298 行、WFT 多 151 行、SMH 多 1002 行。
3. **SMH 新产品自 2011-12-21 起**：它的历史段从这一天开始，指标要从这里重新积累（是否如此处理，待 T01 的历史段规则确定）。
4. **SHLD 2018-03-28**：复权价在这一天出现约 −17.7% 的非市场变化。信号使用复权价（I4），回放时这一天的复权收盘可能产生虚假的下跌与跳空。是否需要特殊处理，由产品经理裁定。
5. **SHLD 2017-11-08 缺价**：按 I2，这一天是"缺价"，回放中应出现一次数据中断。
6. **GMCR 末尾两天**：成交量为 0 的平盘行会被当作正常日线参与回放。
