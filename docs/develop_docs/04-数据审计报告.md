### 3.2 SHLD 2014-04-07"分红" 9.52618（PM-05）

**结论：与 Lands' End 分拆价值大致相符（实际上精确相符），数据不修改。**

- 分配比例为每股 SHLD 获得 0.300795 股 Lands' End（LE），登记日 2014-03-24，分配完成日 2014-04-04。
- LE 于 2014-04-07 开始常规交易。SHLD 的除权日推断为 2014-04-07，与数据源记录的日期一致。来源写明附权与除权两个市场一直持续到分配日，但没有直接写出除权日。
- LE 在 2014-04-04 的 when-issued 收盘价约为 31.67 美元。这个数取自二手来源（美联社稿：4-07 上午跌 2.17 至 29.50）反推，SEC 文件中没有价格。
- 估算：0.300795 × 31.67 = **9.52618 美元**，与数据源记录的 9.52618 一致到小数点后 5 位。说明数据源按 LE 的 when-issued 收盘价计算分拆价值，并把它当作现金分红计入复权。
- 分拆前 Lands' End 向 Sears 的子公司支付了 5 亿美元现金股利。这笔钱不分给 SHLD 股东，与这条记录无关。
- 来源：
  - Sears 新闻稿（8-K 附件 99.1）：https://www.sec.gov/Archives/edgar/data/1310067/000119312514100980/d693657dex991.htm
  - Sears 8-K（分配完成）：https://www.sec.gov/Archives/edgar/data/0001310067/000131006714000009/shcform8-kxlandsenddisposi.htm
  - LE 信息说明书：https://www.sec.gov/Archives/edgar/data/0000799288/000119312514100537/d632333dex991.htm
  - 价格（二手来源）：https://www.heraldnet.com/2014/04/07/lands-end-starts-trading-as-public-company/

## 6. 对后续回放的影响

1. **VRX**：回放使用拼接后的文件，2018-07 不会再被误判为数据结束；拼接点没有价格跳变，也没有复权系数变化。
2. **SHLD、WFT、SMH、GMCR**：回放必须按 `config/listing_periods.csv` 截取，domain 已有 `clip_history_to_listing`。不截取的话，场外报价、平盘占位行和另一证券的历史会混进来：SHLD 多 298 行，WFT 多 151 行，SMH 多 1002 行，GMCR 多 2 行。
3. **SMH 新产品自 2011-12-21 起**：按 I10，这一天是新历史段的起点，指标从这里重新积累，满 W + N 条之前为"不可计算"。
4. **SHLD 2018-03-28**：已按 PM-03 更正。回放必须通过 `MarketDataLoader` 取数，才能用上更正后的复权价，不会出现虚假的下跌与跳空。
5. **SHLD 2017-11-08**（PM-04 更正措辞）：这是**一个缺价日**（m = 1）。回放按 I2 处理为 DATA\_ISSUE，观察重置；它**不是"数据中断"**，中断需要连续 G + 1 天缺价。
6. **SHLD 2014-04-07**：Lands' End 分拆价值已计入复权，除权日不会表现为假暴跌。
