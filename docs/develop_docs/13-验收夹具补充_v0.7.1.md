## 2. F1–F5 完整行情的构造规则（P-04）

F 组是端到端验收：从日线计算指标，再运行引擎，**不得跳过历史长度检查，也不得注入前态**。

| 项 | 规则 |
| --- | --- |
| 交易日历 | 夹具自带：自 2009-01-05（周一）起的连续工作日（周一至周五），无节假日；所有日期都有日线，无缺价 |
| 峰值前历史 | 峰值日之前（含峰值日）共 **90 根**日线，收盘全部为 100。峰值日是其中最后一根（F1 为 c−1，F2–F5 为 e0、f0、g0、h0）。90 ≥ W + N = 83，峰值日当天已可计算 |
| 峰值后收盘 | 按 v0.6 第 7.2 节的路径。**F2 延长**：e21 = 90、e22 = 91、e23 = 92（即"此后每日上涨 1"） |
| 开盘价 | O\_t = C\_{t−1}；第一根 O = C |
| 最高、最低 | H\_t = max(O\_t, C\_t) + 1，L\_t = min(O\_t, C\_t) − 1 |
| 复权价 | 与原始价相同；无公司行动 |
| 成交量 | 每日 1,000,000 |
| 参数 | N = 20；atr\_basis 取 PEAK 与 MIN 各跑一次，两者结果必须相同（峰值日 ATR = 2，峰值后任何一日 TR ≥ 2，所以**初始启动**时 MIN 取到的仍是 2）。这只适用于初始启动：解除后若出现新高点，新峰值日的 ATR 不一定是 2，测试不得把启动分母写死为 2。F 组中 PEAK 与 MIN 结果相同，不能据此证明 MIN 实现正确，MIN 由 S12 专门验收 |

由此：峰值日 ATR₂₀ = 2，ATR\_ep = 2；开盘等于前收，跳空分数恒为 0，R2 不触发；SMA10 由收盘直接计算（F1 c0 = (9 × 100 + 70) / 10 = 97.0，与 v0.6 表一致）。

## 4. 每个夹具都要检查的内部字段与不变量（P-07）

**不变量**（作为通用断言，对所有夹具和以后的真实回放都运行）：

3. H\_d 只在"关注且 downgraded = 是"时有值；加重当日清空。
4. release\_path = TWO\_STAGE 时 xc 恒为 0。
5. 解除当日不产生 STABILIZED、RECOVERY\_OBS、RECOVERY\_REVOKED、RECOVERY\_FAIL。
6. 缺价日末尾 prev\_confirm 为假。（P-23）每次 RECOVERY\_OBS 开启的确认，至多以一个事件结束：RECOVERY\_REVOKED（任何原因）或 RECOVERY\_FAIL，二者只能有一个；新低处理前，上一交易日的确认尚未撤销时，以 RECOVERY\_FAIL 结束该确认，不另发 RECOVERY\_REVOKED（P-29）；确认在此前已被撤销时，RECOVERY\_FAIL 只终止观察周期，不算再次结束该确认（S22）。
