### 1.1 入选规则（发起人 2026-10-14 裁定方向；细节在 T08d-2 登记）

**候选池**：在 NYSE 或 Nasdaq 上市的普通股与 ADR。

- **排除**：
  - 中国大陆、香港、澳门的发行人；
  - 优先股、权证、单位、权利、ETF、ETN、封闭式基金。
- **待登记**：证券类别的判定规则、发行人所在地的数据来源，在 T08d-1 探查结果出来后登记，送复核。

**季度筛选**（只用筛选日当时可得的信息，没有前视）：

- **筛选日**：每年 1、4、7、10 月的第一个交易日，2010Q1 至 2019Q4。
- **处理顺序**（ChatGPT R5-07）：
  1. **只在生成开发期选参集时**排除探索集的发行人；生成验证集时不做这一步（ChatGPT R6-02）；
  2. 逐只证券检查资格（见下）；
  3. **按发行人确定代表股类**：已有固定股类的发行人，只用该股类，其他股类不参与竞争；首次出现的发行人（包括验证期才首次出现的），取当次成交额中位数最高的合格股类，**并列按稳定标识的字典序**，此后固定。"首次出现"指发行人**首次在某个筛选日有至少一个股类通过第 2 步资格检查**，不要求当次进入前 N\_u 名（Gemini 最终核查 R2）；

  5. 合格的代表证券不足 N\_u 只的，全部入选，在报告中注明当季数量。
- **资格**（截至筛选日前一交易日，ChatGPT R5-08）：
  - **交易活跃状态代理**：最近一条有效日线距筛选日不超过 5 个市场交易日；最近 63 个市场交易日中，有效日线至少 57 个（90%）。这只证明"近期有交易记录"，**不是已核实的上市状态**，可能有几日的滞后，在报告中如实披露。不用现在的证券主表推断当时的状态；
  - 证券类别按当时已知的信息判定（判定规则在 T08d-2 中登记）；
  - **自本段有效历史起点起**至少有 83 个有效日线，即筛选日前一交易日已处于第 3 节的公共可评估掩码内（刚发生 DATA\_BREAK、处于新历史段预热期的证券不合格）；
  - 最近 63 个有效日的原始收盘价中位数 ≥ 5 美元；
  - 最近 63 个有效日的日成交额（原始收盘 × 原始成交量）中位数 > 0。
- **入选期间**：[筛选日, 下一筛选日)。

**多股类**：探索集证券的同一发行人的其他股类，一律剔除。其他发行人的代表股类一经确定，开发期与验证期都沿用；该股类退市而另一股类仍上市的，按退市处理，不换股类。

## 2. 严重下跌事件集（取代原 5.3）

### 2.1 记号与口径

- 只按**有效日线**计算：缺价日不计入窗口，也不计入天数。下文的"日"一律指有效交易日（I18）。
- **数值比较**：
  - 价格与价格的比较（≥ 峰值、跌破低点、等于最低）：用入库的六位小数量化值，精确比较，不加容差。
  - 比率与阈值的比较（G、B、V、R 的两项，以及第 3 节的 S1）：一律用十进制定点计算（Python `decimal`，精度 28 位，ROUND\_HALF\_EVEN），量化到 12 位小数后精确比较。ATR₂₀ 用量化后的价格以同样方式计算。边界行为由夹具 19 约束。
- C\_j：第 j 日的收盘。e\_prev：同一证券、同一事件集的上一事件的结束日（没有时为 −∞）。
- **受限窗口最高**：H\_j = max{ C\_k : max(j − 62, e\_prev, seg\_start) ≤ k ≤ j }，可以包含上一事件的结束日；**不跨越 DATA\_BREAK**，seg\_start 为本段有效历史的起点。
- **事件内的记号**：
  - 开始日 s；峰值日 p；峰值收盘 C\_p；
  - L\_j = min{ C\_k : p ≤ k ≤ j }，截至 j 的最低收盘；
  - **恢复锚** ℓ\_j：收盘等于 L\_j 的**最近**一日，再次触及相同低点也会移动；
  - **恢复高点** M\_j = max{ C\_k : max(ℓ\_j, j − W\_Q + 1) ≤ k ≤ j }，**W\_Q = 20**。只看恢复锚之后、且最近 20 日内的最高收盘（Gemini G-T8b-1 陷阱 1）；
  - **报告谷底**：结束后，收盘等于最终最低收盘的**最早**一日。它与恢复锚是两个不同的字段。
- **尺度**：E\_pct 用比例。E\_atr 的开始用当日 ATR₂₀(j)（SMA ATR，不冻结），开始之后的判断都用开始日冻结的 A\_s = ATR₂₀(s)。

| 量 | E\_pct | E\_atr |
| --- | --- | --- |
| 开始度量 G\_j | 1 − C\_j / H\_j | (H\_j − C\_j) / ATR₂₀(j) |
| 开始阈值 T | X\_pct | X |
| 距峰值 B\_j | 1 − C\_j / C\_p | (C\_p − C\_j) / A\_s |
| 距恢复高点 V\_j | 1 − C\_j / M\_j | (M\_j − C\_j) / A\_s |

### 2.2 逐日状态机

每只证券、每个事件集各自运行。一个事件的状态有**进行中**、**待确认**、**已确认**三种；另有一个**搜索**过程，寻找下一个事件。每日按下列顺序判断；一旦命中终止性分支（结束、确认、并入），该事件当日不再往下判断。

**处理顺序**（ChatGPT R5-01、R5-02）：同一时刻只有一个事件处于"进行中"或"待确认"，**不并行建立后继事件**。

- 上一事件确认之后，搜索从其结束日 e 的次日起**回放**：把 (e, 确认日] 之间已经过去的日子按顺序重新判断一遍。这是事后评价标签的构造方式，不涉及实时信号的回滚。
- 所以，一个事件建立时，它之前的全部事件都已确认，不存在"后继事件已确认、前序事件却还可能并入"的情形。

**搜索**

- **可开始的最早日**（Gemini 最终核查 R2）：= max(本段有效历史中公共可评估掩码成立的第一日, 上一事件结束日 e 的次日)。
  - 掩码成立日自然晚于 H\_j 可计算的第 63 个有效日；
  - 没有上一事件的，第二项不适用；有上一事件的，从其确认日之后回放（见上），无论结束原因。
- 若 G\_j ≥ T：s = j；p 取 H\_j 所在日（并列取最近）；n = 1（自 s 起的有效日数），q = 0；进入**进行中**。

**进行中**（j > s 的每一日：n 加 1，然后更新 L、ℓ、M）

1. **(a) 回到峰值**：C\_j ≥ C\_p → 结束日 e = j，原因 a，当日确认。
2. **(c) 上限**：n = 252 → e = j，原因 c，当日确认，标"上限"。
3. **安静计数**：R 与 Q 同时成立则 q 加 1，否则 q = 0。
   - **R（已收复）**：恢复比例 (C\_j − L\_j) / (C\_p − L\_j) ≥ ρ\_end，或 B\_j < T / 2。进行中时 L\_j < C\_p 恒成立，分母不为 0；
   - **Q（未再恶化）**：V\_j < T / 2。

   q = 10 → 暂定结束日 e = j，原因 b，进入**待确认**，w = 0。

**待确认**（e 之后的每一日：n 加 1，w 加 1，然后更新 L）

1. **并入**：C\_j < L\_e（跌破暂定谷底）→ 并入原事件，回到**进行中**，q = 0；峰值不变，谷底整段重算。并入当日 n = 252 的，当日以 (c) 结束并确认。因为后继事件尚未建立，没有需要撤销的东西。
2. **回到峰值，提前确认**：C\_j ≥ C\_p → 当日确认，结束日仍为 e，原因 b，标"确认期内回到峰值"。
3. **上限截止**：n = 252 → 当日确认，结束日仍为 e，原因 b，标"确认期在上限处截止"。
4. **正常确认**：w = 20 → 当日确认，结束日为 e，原因 b。

确认之后，从 e + 1 起回放搜索。

- **回放连续识别多个后继事件**（ChatGPT Q6-1）：回放不在找到第一个后继事件时停止，而是按同样的规则逐日推进，直到追上当前日期；其间可能建立、结束、确认多个事件。每个事件的 n 从它自己的开始日计算。
- **两层可确定日期**（ChatGPT Q6-1、R7-01）：
  - **事件标签的可确定日期**：等于事件自己的确认日与它全部前序事件的确认日中最晚的一个。后继事件的历史结束日可能早于前序的确认日，但它的标签不能视为在这个日期之前就已知道。
  - **指标的可确定日期**：每个评价指标另记一个日期，等于它所需的事件标签、相邻事件边界与观察窗口**全部**确定的最晚日期。公式（Gemini 最终核查 R2）：
    - 窗口未被下一事件截短的：max(本事件标签的可确定日期, 观察窗口的终点)；
    - 窗口被下一事件截短的：max(本事件标签的可确定日期, 下一事件标签的可确定日期)；
    - S1 与 H1：等于事件标签的可确定日期；解除后的 Q、Q\_L 指标与恢复观察后的 Q 指标：各自观察窗口的终点（严重不利变化的判定不依赖事件标签，第 3C 节）。
  - 第 5.3 节按**具体指标**的可确定日期判断是否归入前段。

**取消"从恢复高点再跌满一个阈值即并入"**（v5 的并入条件 ②）。理由：统计区间是 [p, 报告谷底)，没有跌破原谷底的二次下跌并入后，会落在统计区间之外，既不属于原事件，也不能成为新事件（Gemini G-T8b-2 ①）。这样的下跌由回放搜索独立识别为下一事件。

**结束后**

- **252 日是硬上限**：任何事件的 [s, 结束或确认日] 都不超过 252 个有效日。
- **截尾**：确认之前遇到数据终点，或 [p, 确认日] 内有缺价日的，标截尾并记原因：
  - **右端截尾**：数据终点、退市、必需区间终点、期间终点（这四种分别计数）；
  - **缺价截尾**：缺价、历史断点。
- **上限延续**：上一事件以 (c) 结束，且本事件的 s ≤ e\_prev + 63 的，标"上限延续"，单列报告。
- **依赖未决**（ChatGPT R5-02）：数据终止时某事件仍在待确认，(e, 数据终点] 内不建立后继事件。这一区间记"依赖未决区间"，报告其证券日数；其中的下跌不计入任何口径，也不判 H1。
- **不可评估的原因**（ChatGPT R5-13、R6-04）：[p, 报告谷底] 内有任何一日不在公共可评估掩码内的事件，两种口径都不计，也不判 H1。原因分开记录，可以并存：
  - **预热不可评估**：该日自本段有效历史起点起不满 W + max(N) 个有效日（新上市，或 DATA\_BREAK 后的新历史段）；
  - **缺价截尾**：该日是缺价日，或处于 DATA\_BREAK 的断段中，按既有缺价截尾处理。
  - 两种原因同时出现的，两项都记。汇总时按事件计一次，另报各原因的事件数（可重叠）。

**统计归属与无重叠**

- 每个事件的统计区间为 [p, 报告谷底)。
- 下一事件的峰值 ≥ e\_prev；上一事件的报告谷底 ≤ e\_prev，以 (a)、(b) 结束的还严格早于 e\_prev。所以相邻事件的统计区间不重叠，唯一可能共享的 e\_prev 只属于下一事件。
- **R\_E 的搜索范围**：截至 min(报告谷底 + Y\_max, 下一事件的峰值日)，包含下一事件的峰值日当日。

## 3. 事件结果与 S1（取代原 5.4、5.5）

**公共可评估掩码**（Gemini G-T8b-6 ①）：

- 第 k 日"可评估"，指同时满足：
  - 当日不是缺价日；
  - 不处于 DATA\_BREAK 之后的断段中；
  - 自本段有效历史起点起，已满 W + max(N) 个有效日。max(N) 取**所有被比较方法中最长的预热要求**，包括全部候选、R0 与基线 B1、B2。按现网格为 63 + 20 = 83 日；若某方法有更长的预热，取其长者。
- 掩码只由价格数据决定，**对所有方法相同**。事件搜索、S1、H1、S2、h\_tail、占用率与 F 一律以它为准。

**日末状态**：方法 M 在可评估的第 k 日，日末状态为"在警"或"不在警"。

- 在警：第 k 日处理结束后，存在进行中的预警（关注或警戒）。
- 预警以 RELEASE 或 DATA\_BREAK 终止的，当日不在警。
- **在警戒**：日末等级为警戒。

**延续到谷底的预警段**：

- 对事件（峰值日 p，报告谷底 k）与方法 M：若 M 在第 k − 1 日日末在警，取包含第 k − 1 日的、连续**有效日**日末在警的最长一段，其首日记为 f₀。
- 若第 k − 1 日日末不在警，则没有延续到谷底的预警段。

**四类结果**（对每个已确认、未截尾、非预热不可评估的事件，以及每个方法）：

| 类别 | 判定 | S1 |
| --- | --- | --- |
| **持续覆盖** C | 有延续到谷底的预警段，且 f₀ < p | 0 |
| **段内起始** N | 有延续到谷底的预警段，且 p ≤ f₀ < k，记 f = f₀ | (C\_p − C\_f) / (C\_p − C\_k) |
| **谷底前末段未覆盖** U | 没有延续到谷底的预警段 | 1 |

- **S1 的名称与含义**（ChatGPT Q5-2）：S1 称为"**谷底前持续预警段起点得分**"，衡量"把你带到谷底的那段预警是从什么时候开始的"。它**不是**首条通知的及时性。例如峰值 100、谷底 60：A 在 98 提醒、随后解除、在 65 重新提醒；B 到 80 才首次提醒并持续到底。S1 认为 B 更好，因为 B 没有提前解除；但不能据此说 B 的首条通知更及时。
- **U 的含义**：包括"从未提醒"和"曾提醒、谷底前解除且没有再提醒"两种，分开计数报告。
- S1 的分子分母都是收盘价之差，E\_pct 与 E\_atr 在同一 (p, k, f) 下的 S1 完全相同。按第 2.1 节的十进制口径计算。
- **另报首次提醒的指标**（ChatGPT Q5-2）：
  - [p, k) 内首次实际 START（或此前已在警则记"峰值前已在警"）的日期与已实现跌幅；
  - 首次提醒后到谷底前，日末不在警的日数。
- **ESCALATE 不单独构成新通知**。升级的及时性另用**警戒口径 S1w** 报告，在同一个延续到谷底的预警段 [f₀, k − 1] 上衡量首次到达警戒的时刻（Gemini 最终核查 R2）：该段在 p 之前已处于警戒的，记 0；在 [p, k) 内首次处于警戒的，取首个警戒日 f\_w，记 (C\_p − C\_{f\_w}) / (C\_p − C\_k)；该段全程从未处于警戒、或没有延续到谷底的预警段的，记 1。谷底前合法降级（警戒 → 关注）不改变 S1w。另报"预警段全程只有关注、从未升为警戒"的事件占比。S1w 只报告，不进门槛与排序（第 11 节）。
- **确认性结论的范围**（ChatGPT Q5-3）：本轮的门槛与确认性比较都针对"是否处于预警"，**不证明警戒升级是否及时**。S1w 与"全程只有关注"的占比必须在报告中披露。
- **谷底日**：谷底日当天解除不影响分类，因为预警段只看到 k − 1 日。另行报告谷底日日末是否在警、谷底日解除的次数，以及这些解除当日的跌幅、当日回吐与解除后 Q、Q\_L 窗口的结果。

### 3.1 防止长期挂起

- 分界：选参集全部证券该统计量的第 1/3 与第 2/3 分位 b₁、b₂，登记时计算并固定（只用价格，不涉及评价结果）。

### 3A. S2 恢复后在警占比

- **目标窗口** Ω\* = [R\_E, R\_E + Y\_cap − 1]，含 R\_E 当日。
- **观察窗口** Ω：Ω\* 截至两个界中较早者，即"下一事件的峰值日 − 1"与数据终点。截短原因取较早的界，同日记"数据不足"。
- **S2** = Ω 内日末在警的可评估日数 ÷ Ω 内的可评估日数。在警不论属于哪一次预警；不因一次解除就停止观察。
- 主口径窗口须至少有 n\_min 个可评估日。

两种口径见第 3B 节。

### 3B. 各指标的两种口径（取代原 5.11）

**原则**：第二口径只改变**未知部分**（未观察到的日子与不可评估日）的处理，不推翻已观察到的事实。

**补足口径的窗口分类**（S2⁺ 与 h⁺ 共用，ChatGPT R6-01）：

| 类别 | 判定 | 补足方式 | 纳入条件 |
| --- | --- | --- | --- |
| A 完整、可评估日充足 | 观察到目标终点，可评估日 ≥ n\_min | 不可评估日记为在警 | 纳入 |
| B 完整、可评估日不足 | 观察到目标终点，可评估日 < n\_min | 不可评估日记为在警 | 窗口全长 ≥ n\_min 即纳入 |
| C 右端观察不足 | 终点由数据终点决定 | 补足到目标终点（对 S2 为 Ω\* 与"下一事件的峰值日 − 1"中较早者），未观察日与不可评估日都记为在警 | 补足后长度 ≥ n\_min 即纳入 |

### 3C. 恢复参考点、恢复观察与解除后不利变化（取代原 5.4 的解除归属、5.6–5.8）

- **恢复参考点 R\_E**：报告谷底 k 之后，首个回升占比 (C\_j − C\_k) / (C\_p − C\_k) ≥ ρ 的有效日，按第 2.1 节的十进制 12 位比率口径比较。搜索范围见第 2.2 节；范围内找不到的记"未恢复"。ρ 待批准（拟定 0.5）。
- **恢复与解除的描述**：每个 RECOVERY\_OBS、RELEASE 报告距谷底的交易日数、回升占比、距低点涨幅。
- **恢复观察的评价**（只报告，不设门槛，不进第 10A 节）：每个 RECOVERY\_OBS 之后 Q 个有效日内，是否发生 RECOVERY\_FAIL、是否出现下述严重不利变化；每次预警内恢复观察的反复次数。
- **解除的评价单位**：每次 RELEASE 独立评价，只看其后的 Q 与 Q\_L 窗口；窗口之后的新下跌不追溯到这次解除。RELEASE 可以发生在任何事件之外。纳入与否按信号日是否在入选期间内（第 1.2 节）。
- **解除后严重不利变化**：RELEASE 日为 r、收盘 C\_r。观察窗口为 r **之后**（不含 r 当日）的 Q、Q\_L 个有效日（Q\_L > Q）。窗口内任一日满足下列之一即为严重不利：
  1. 收盘较 C\_r 下跌 ≥ y\_pct；
  2. 收盘较 C\_r 下跌 ≥ y\_atr × A\_r，A\_r = ATR₂₀(r)（SMA ATR）；
  3. 收盘跌破所解除预警的 L\_ep（按所评价规则版本的 L\_ep 定义）。

  ① ② 为比率，按第 2.1 节的十进制 12 位口径与阈值比较；③ 为价格比较，用量化值精确比较。
- **窗口完整**：窗口有效日数达到 Q（或 Q\_L），全部在必需区间与期间终点之内，且**不跨越 DATA\_BREAK**；否则记不完整，按第 3B 节处理。
- **另报**："事件 [p, 报告谷底) 内发生过 RELEASE"的事件占比与次数（与 05 号 F-05、06 号口径一致），不设门槛。

- **占用率的两种口径**：合并证券日口径与跨证券中位数口径（门槛用后者）。

## 4. 硬约束 H1：不晚于本段下跌的旧规则触发日（新增）

**含义**（发起人 2026-10-14 裁定）：

> 对每一段大跌，以它自己的峰值为起点，按旧规则（v0.7.1）的启动门槛，算出"旧规则在这段下跌中最早会报警的日子"F\_ref。新规则在 F\_ref 当日收盘时必须处于预警中。此前已经在预警中、一直持续到那天的也算满足；不要求为这段下跌再单独发一条通知。

F\_ref 是一个**名义日期**，不一定等于旧规则实际发通知的日期。旧规则实际的结果另行报告，不作判定（ChatGPT R5-05）。

**参照规则**：v0.7.1 的启动条件（S 路径与跳空路径），参数取参考候选 c385（网格序号 385，N = 20）；数值协议（包括容差）冻结为 T06 V0 回归时的口径，F\_ref 的启动条件判定一律沿用。

**F\_ref 的计算**：对事件（峰值日 p，报告谷底 k），F\_ref 是 [p, k) 内、公共可评估掩码之内，第一个使下列条件成立的日子 j：

- **峰值锚定为本事件的峰值，回看不超过 63 日**（Gemini 最终核查 R2）：S 路径的回看窗口取 [max(p, j − 62), j]。
  - j ≤ p + 62 时，窗口内的最高收盘就是 C\_p（[p, j] 内不会有更高的收盘，因为回到 C\_p 即以 (a) 结束），峰值日取 p；
  - j > p + 62 时，与 v0.7.1 的 W = 63 一致，峰值取 [j − 62, j] 内的最高收盘日 p\_j（并列取最近）；
  - ATR 按 c385 的 atr\_basis，以所取的峰值日计算（v0.7.1 第 1.3 节的定义）；
- 跳空路径照常按当日开盘与前一日收盘判断；
- 不使用上一段下跌的旧高点，不受 R0 实际状态（是否挂着预警、last\_release 在哪里）的影响。

区间内条件从未成立的，F\_ref = 无。这段下跌达不到旧规则的启动门槛，不判 H1，由未提醒率门槛 m 约束。

**判定**：对 E\_pct、E\_atr、E\_pct10 中每个已确认、未截尾、非预热不可评估的事件，若 F\_ref 存在，候选必须在 F\_ref 当日日末在警，否则记一次违反。候选的违反次数必须为 0，开发期与验证期都检查。

- 在 F\_ref 之前已在警、一直延续到 F\_ref 的，满足要求。
- 在 F\_ref 之前在警、但在 F\_ref 当日或之前已解除的，违反。这堵住了"早早发出警报、在旧规则触发之前就解除"的路径。
- 峰值锚定消除了"旧高点使 S 路径在 p 日成立"的问题（ChatGPT R5-05）：p 日距本事件峰值的回撤为 0，S 路径不会在 p 日成立。但若 p 日自身满足有效跳空条件（例如上限延续时，新事件的峰值是上一事件的结束日），F\_ref 仍可等于 p（ChatGPT Q6-2）。

**截尾与不可评估**：

- 右端截尾、前缀完整：设 k\* 为截至截尾点所见最低收盘的最早一日。若 F\_ref ∈ [p, k\*)，按上式判定并计入；否则记"未知"。F\_ref 只依赖价格与本事件的峰值，判定不会因后续数据而改变。
- 缺价截尾、依赖未决、预热不可评估：一律记"未知"。
- "未知"始终单列，报告中不得表述为"不违反"。

**另报**：

- 旧规则（R0）实际首次在警日与 F\_ref 的差异分布；
- 各方法在 F\_ref 当日的已实现跌幅分布。

**影响预告**：k₁ 大于 c385 的候选、x₁ > 0 的候选，在旧规则刚达到启动门槛、跌幅还小于 x₁ 的事件上**可能**违反 H1（跳空等其他路径可能使日期相同，所以不是必然）。这些维度的可用取值可能被压到与 c385 相当，除非 T08c 的规则研究让候选在这些事件上同样及时。减负主要只能来自从未发展成事件的启动，以及投递层的合并。

## 5. 选参流程（取代原 5.12）

### 5.1 顺序

1. **规则研究**（T08c 第一段，只用探索集）：研究 A-01–A-05、A-07，冻结为 v0.9 候选规则。允许反复看结果。
2. **工程调试**：用构造数据和探索集完成选参流水线的调试。
3. **登记前的可行性检查**（Gemini G-T8b-3 ③，ChatGPT R5-06、R6-03）：在探索集上运行拟登记的全部候选，**按顺序**把每个候选归入一类：
   1. **已知违反**：至少一个可计算的条件（组合约束、H1、可计算的门槛）不满足；
   2. **证据不足**：没有已知违反，但存在在探索集上无法评价的项目；
   3. **探索检查满足**：全部探索检查项目都可评价，且都满足。

   第 10A 节的正式最小样本（例如每个波动组至少 20 只证券）在 27 只探索股上无法满足。这一条**不列入探索检查项目**，对所有候选单列为"探索集无法验证"，否则所有候选都只能归入第 2 类。门槛本身若因样本太少在探索集上无法计算，才算第 2 类的"无法评价的项目"。

   **推进规则**：
   - **所有候选都属"已知违反"**：必须在登记前返工（修改规则、网格或拟定门槛），报发起人。这仍属探索期，允许。
   - **存在"证据不足"或"探索检查满足"的候选**：可以进入登记。证据不足的候选，逐项列出无法评价的项目及其风险，由发起人在登记时确认。
   - 不因探索样本不足而降低正式的最小样本要求，也不把"证据不足"描述为已经证明可行。探索集上满足不保证选参集上合格，这一点在登记时写明。
4. **登记**（SR-M1′，发起人批准；在看任何选参集结果之前）：
   - 候选全集与网格序号；
   - 门槛数值 m、p、p\_L、s、o\_max、o\_tail、h\_tail、F（由产品经理依据探索集的分布写出拟定值与理由）；
   - 第 7 节的待登记数值、第 10A 节的最小样本、波动分组的分界；
   - 入选规则的全部细节、选参集名单、数据清单哈希、T08d 的验收结果；
   - 第 3 步可行性检查的结果。
5. **选参集运行**：按第 5.4 节的纪律进行；按第 5.2 节选出一个候选，或者没有合格候选。
6. **冻结**：规则、候选、全部登记值、代码版本与数据哈希。发起人可以否决冻结；否决后重新研究的，记为新的研究轮次，该选参集即"已使用"。
7. **验证集运行，只一次**（SR-M5）。

### 5.2 资格与排序

**第一步：逐个判定资格**。候选同时满足以下各项，才"合格"：

1. **组合约束**（Gemini G-T8b-1）：
   - **10 号第 1A.1 节的全部合法组合约束**：x₂ > 0 ⇒ t11\_full = ON；long\_path = X1 ⇒ x₁ > 0；long\_path = X2 ⇒ x₂ > 0；r2\_floor = ON ⇒ x₁ > 0；x₁ > 0 且 x₂ > 0 ⇒ x₂ > x₁；
   - **另加正式组合约束**：t11\_full = ON ⇒ x₂ > 0（与上合为 ⇔）；x₂ > 0 ⇒ x₁ > 0；long\_path ≠ OFF ⇒ release\_hyst = EFFECTIVE；0 < h < 1；
   - 以 T08a 的 `is_formal_candidate` 实现为准，规格与实现不一致时停止。
2. **H1** 违反次数为 0。
3. **门槛**全部满足：E\_pct 与 E\_atr 都要满足；有两种口径的，两种都要满足；**全体以及低、中、高三个波动组各自**都要满足（h\_tail 按第 3.1 节的例外规则）。
4. **证据充分**：不处于第 10A 节的"证据不足"。
5. **稳健性**（Gemini G-T8b-3 ①）：
   - 相邻候选 = 同一规则版本与结构组合内，每个数值维度与阈值维度各自改取网格中的相邻值（x₁、x₂、h 包括在内；边界值只有一个相邻值）。
   - 每个满足组合约束的相邻候选，须满足第 3、4 项，且 S1 不劣于本候选超过 Δ₁、S2 不劣于本候选超过 Δ₂。
   - **不要求相邻候选满足 H1**。沿 k₁ 或 x₁ 增大方向的相邻候选通常启动更晚（跳空等其他路径可能使日期相同），要求它们也满足 H1，会使合格集合大幅收缩甚至为空。H1 只约束被选中的候选本身，相邻候选只用于检查性能退化。
   - 违反组合约束的相邻候选跳过。

**第二步：在合格集合中逐层排序**：

1. 求 S1 均值（E\_pct 与 E\_atr 的平均，主口径）的最小值 S1\*，得 A₁ = { S1 ≤ S1\* + ε₁ }；
2. 在 A₁ 内求 S2 均值（两者的平均，主口径）的最小值 S2\*，得 A₂ = { S2 ≤ S2\* + ε₂ }；
3. 在 A₂ 内，按 F 口径的向上事件频次（START 与 ESCALATE 合计，每证券年，跨证券中位数）升序；
4. 再按网格序号升序，取第一个。

**合格集合为空**：停止，请发起人裁决，不放宽门槛与 H1。

START、ESCALATE 分别报告；全部进展事件数作为附加负担指标报告。

## 8. 价格比较容差（B-05）

1. **构造测试**：
   - 远离边界：价格整体乘以 {0.01, 0.1, 10, 1000}，所有比较两侧的相对差距都 ≥ 10⁻⁴ 的输入，离散结果必须不变；
   - 边界处：单独构造量化与容差边界两侧的输入，记录缩放后允许发生的变化，作为已知行为写入测试，不要求不变。
2. **实测**：在探索集上，用 V0 比较绝对容差与相对容差的全部离散差异。
3. **相对容差的"参考价"**（Gemini G-T8b-6 ③）：比较 a 与 b 时，参考价取作为基准的一侧 b，容差为 ε\_p × max(1, |b|)。逐类写明：

   | 比较 | 参考价 |
   | --- | --- |
   | 新低：C\_T < L\_ep | L\_ep |
   | 回到峰值、突破：C\_T ≥ P\_ep、C\_T > box\_high | P\_ep、box\_high |
   | 均线确认：C\_T > SMA10 | SMA10 |
   | 跳空：O\_T 与 C\_{T−1} | C\_{T−1} |
   | 日间比较：C\_T 与 C\_{T−1} | C\_{T−1} |
   | 其他价格比较 | 比较式右侧的值 |

   以 `domain/numeric.py` 的比较函数为唯一入口，实现时逐一核对调用点；遇到表中没有的比较，停止并报告。
4. **决定规则**：构造测试通过、且实测差异为 0 的，候选一律切换为相对容差；否则逐项列出差异，由产品经理判定，送复核。
5. **R0 不切换**：R0 的数值协议按第 4 节冻结。若候选切换，在探索集上报告 R0 用两种容差时的 H1 差异。
6. **规格措辞**：10 号第 1.6 节改为"在容差与量化边界之外不改变离散状态"；在 02、11 号登记"事后复权"为探索期的已知限制。

| 项 | 规则 |
| --- | --- |
| 日历块 | 开发期与验证期分别按各自的市场交易日历划分，各从期内首个交易日起每 63 个交易日为一块，全部证券共用；末尾不足 63 日的并入前一块；两个期间分别登记起点与种子 |
| 抽取 | 每次重复，从 I 只证券中有放回抽 I 次，得 w\_i；从 J 个块中有放回抽 J 次，得 v\_b；格 (i, b) 的权重为 w\_i × v\_b。若第 9.1 节判定需要，时间维度改为**相邻块连抽**：每次连抽 L\_b 个相邻块，L\_b 在附录 S 中登记 |
| 尝试次数 | B = 2000，种子登记 |
| 共同权重 | 同一次重复中，所有候选、基线与 R0 用同一组权重 |
| 归组 | 事件按（证券，峰值日所在块）；RELEASE、RECOVERY\_OBS 按（证券，信号日所在块） |
| 统计量 | 主口径为事件加权均值（S1、S2）与解除加权比率（不利率）；证券等权均值另报 |
| 无效重复 | 任一相关统计量的分母为 0 的重复记为无效；有效次数 B\_v。B\_v < 0.99 B 的，方法判为不适用 |

**主检验**：

- 唯一的主检验是单侧百分位自助检验。改进量 Δ = 基线均值 − 候选均值，原假设 Δ ≤ 0。
- p = (1 + #{有效重复中 Δ\* ≤ 0}) / (B\_v + 1)；最小可报告的 p 为 1 / (B\_v + 1)。Holm 校正作用于这个 p。
- 单侧 95% 下界取 Δ\* 的第 5 百分位，只作描述；判定以 Holm 校正后的 p 为准。

### 9.1 模拟检验

**冻结要求**：模拟运行之前，冻结数据生成方案、参数、真值的计算依据与验收统计量，写成附录 S，经 ChatGPT 复核。不得根据模拟是否通过修改生成方案。替代推断方法用同一套冻结场景验收。附录 S 在 SR-M1′ 之前冻结并完成模拟；探索集上的规则研究不依赖附录 S，可以先行。

**两层模型**：

- **主验收层**：生成有界的成对得分，调用正式评价所用的同一套指标、窗口纳入规则与重采样函数。验收结论以本层为准。
- **诊断层**：正态差值模型，只用来分别检查各种相关结构的影响，不作验收依据。

**共同结构**：

1. I 只证券，J 个块（每块 63 日）。
2. 事件数：格 (i, b) 的事件数 ~ Poisson(λ\_i κ\_b)。λ\_i ~ Gamma（均值 λ̄，形状 k\_λ）；κ\_b = exp(σ\_κ z\_b) 归一化到均值 1，z\_b 为 AR(1)，系数 φ。
3. 潜在效应：证券效应 u\_i、块效应 g\_b（AR(1)，系数 φ\_g）、事件效应 ε\_e。
4. 事件数与效应的相关：log λ\_i 与 u\_i 的相关系数为 c\_λu，z\_b 与 g\_b 的相关系数为 c\_κg。

**主验收层的生成方式**：

- 每只证券生成一条时间线：按事件数安排事件，给出峰值、谷底、R\_E 与下一事件的峰值；相邻事件的间距可以小于 Y\_cap。
- 每个事件生成一条简化的分段收盘路径（峰值 → 谷底 → 恢复），只为正式函数提供必需的价格字段。
- 两个方法的日末状态由两状态马尔可夫链生成，进入与退出概率是潜在效应的函数。**从不在警转为在警即生成一次新的 START，赋予新的 episode\_id；连续在警属于同一 episode\_id**（Gemini G-T8b-5），以便正式函数唯一判定预警段。
- 两个方法在同一事件集合上配对计算；缺价与不可评估日按设定的比例插入。

**真值**：

- 规模检验（真值为 0）：两个方法的马尔可夫链参数取同一分布，在潜在效应给定时可交换，所以无论事件数与效应是否相关，事件加权改进量的总体真值都为 0。
- 功效检验：把正式的事件加权统计量作用在一个大规模的总体实现上（I × 100 只证券），取其值作为真值，并报告其蒙特卡洛误差。只报告。
- 诊断层：Δ\_true = E[Σ n\_e d\_e] / E[Σ n\_e]，不把截距当作真值。

**场景**：① 跨块共同冲击；② 长事件（以概率 π\_L 跨 4 块，归组按峰值块）；③ 峰值错位（以概率 π\_M 前移或后移一块）；④ 窗口重叠（相邻事件间距取短档）；⑤ 集中贡献（一只证券的期望事件份额为 20%）；⑥ 有效簇少（I = 30，J = 40）；⑦ 事件数与效应相关。

**参数**：用探索集上 R0 与 V3 的结果估计。每个参数登记低、估计值、高三档：

- 尺度参数取 ×0.5、估计值、×2；
- 相关系数、AR 系数与概率参数在合法范围内逐个指定，不用倍乘，不自动截断；
- 每档检查 |φ| < 1、|φ\_g| < 1、相关矩阵正定、概率在 [0, 1] 内。

**验收格与压力格**（Gemini G-T8b-5）：

| 类别 | 内容 | 作用 |
| --- | --- | --- |
| **验收格** | 全部场景在"估计值"档，以及场景 ③、④、⑦ 的低、高档；规模 I = 100 与 I = 600，J = 40 | 主方法必须通过 |
| **压力格** | 场景 ①、②、⑤、⑥ 的高档（强跨块自相关、跨块长事件、单证券大份额、簇少） | 不要求通过；用来标出方法失效的边界 |

**验收标准**：

| 项 | 规定 |
| --- | --- |
| 重复 | 每格 1000 个模拟数据集，每个数据集内 B = 500 次自助，种子登记 |
| 区间 | Δ\* 的双侧百分位区间 [2.5%, 97.5%]；覆盖率 = 区间包含真值的比例 |
| 单格标准 | 覆盖率在 [92.5%, 97.5%]；Δ = 0 时主检验在 α = 0.05 下的单项拒绝率 ≤ 6.5%；S1、S2 两项经 Holm 校正后的族错误率 ≤ 6.5% |
| 放宽的理由 | 1000 次模拟的蒙特卡洛标准误约 0.7%。真实覆盖率恰为 95% 时，单格落在 [92.5%, 97.5%] 之外的概率约 0.03%，几十个验收格全部通过的概率仍在 98% 以上。[93%, 97%] 会让一个正确的方法因多格检验而偶然失败 |
| 临近边界 | 覆盖率在 [92.5%, 93%] 或 [97%, 97.5%]，或拒绝率在 (6%, 6.5%] 的格，用正式的 B = 2000 重跑，以重跑结果为准 |

**适用域与方法选择**（预先登记，ChatGPT R5-09、R5-10、R5-11）：

1. **适用域**：用正式数据估计依赖结构，包括跨块自相关 φ\_g、最大证券事件份额、有效证券簇数。所估计的结构落在哪个模拟格（参数区间）内，哪个格就是"适用域"。
2. **必须全部通过**：所用方法在适用域格上必须同时满足覆盖率、单项拒绝率与族错误率三项标准。任一不满足，按下表升级；升级后仍不满足的，确认性比较记"无法判定"。
3. **按失效原因登记可用方法**：

   | 失效原因 | 可用的升级 | 不能用来解决的 |
   | --- | --- | --- |
   | 时间维度依赖过强（φ\_g 高、跨块长事件） | 时间维度改为相邻块连抽，L\_b ∈ {2, 3, 4}，取通过的最小值 | — |
   | 单只证券份额过大、有效证券簇过少 | 附录 S 可登记一种替代方法（例如以发行人为单位的自助或置换检验），须通过对应格 | 相邻块连抽不能解决这类问题 |
   | 多个原因同时出现 | 同时应用各自的升级；组合后的方法须通过适用域格 | — |
   | 没有通过的方法 | 记"无法判定"，不改用未通过模拟的方法 | — |

4. **模拟完整流程**：附录 S 的每个模拟数据集都执行完整流程：估计依赖结构 → 按上表的冻结规则选择方法与连抽长度 → 计算检验结果。验收的是**这个完整流程**的覆盖率与错误率，而不只是几个固定方法各自的表现。

## 10A. 零样本与证据不足

**两类分母**：

- 由样本决定的分母：事件数、已恢复事件数、证券数、波动组的证券数。对所有候选相同。
- 由候选决定的分母：例如 RELEASE 的完整窗口数、RECOVERY\_OBS 数。

**最小样本**（拟定，待批准；每个事件集、每个波动组、开发期与验证期分别检查）：

| 指标 | 最小样本的分母 | 最小有效样本 |
| --- | --- | --- |
| S1、未提醒率、H1 | 已确认、未截尾、非预热不可评估的事件 | 100（全体）；30（每个波动组） |
| S2 | 主口径纳入的 S2 窗口 | 50；15（每组） |
| s | 完整目标窗口且可评估日 ≥ n\_min | 50；15（每组） |
| h\_tail | 非空、完整观察、可评估日 ≥ n\_min 的未恢复窗口 | 整体 20；分组过关时每组 20（第 3.1 节的例外规则） |
| 解除不利率 p、p\_L | 各自窗口（Q 或 Q\_L）完整的 RELEASE，两个分母分别检查 | 50；15（每组） |
| 波动组的门槛 | 每组已归组的证券 | 20 |

**处理**：

| 情形 | 结论 |
| --- | --- |
| 由样本决定的分母低于最小值 | 停止评价，报告证据不足；不填 0，不当作通过 |
| 结构上不可能有样本（例如探索集没有某个波动组） | 该项"不适用"，只用于描述报告，不适用于门槛 |
| 由候选决定的分母低于最小值 | 该候选"证据不足"，不合格 |
| 验证期出现以上情形 | 记"无法判定"，不称为验证通过 |

h\_tail 的样本很可能不足。不足时停止，由发起人裁决是否删去这项门槛，不在看结果后自行放宽。


## 11. 说明：S1w 不进门槛

Gemini 建议持续覆盖须在峰值日前已处于警戒。这一条没有作为门槛条件采纳，理由：

1. 关注本身就是推送给用户的提醒，产品不要求用户只在警戒时才行动。
2. 本轮的门槛与确认性结论因此只针对"是否处于预警"。**这不证明警戒升级是否及时**（ChatGPT Q5-3）。
3. S1w 与"全程只有关注"的占比必须在报告中披露，发起人据此判断是否需要在后续轮次把升级及时性纳入评价。

如果以后要把 S1w 纳入排序，必须放在网格序号之前，否则不起作用。
