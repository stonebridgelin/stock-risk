# 18 评价模块夹具 v1

编写：产品经理 · 2026-10-15 · 依据：[17 评价协议 v1.1](17-评价协议_v1.md) 第 10 节（夹具 1–44）；实现卡 [T09](../tasks/T09-评价模块实现.md)。

17 号第 10 节要求夹具的期望值由产品经理按规格逐日推导，写入 13 号。为了不使 13 号（生命周期夹具）过长，评价模块的夹具单独成文，即本文档。这只是文档组织上的调整，不改变任何规则。

## 0. 使用方法

- **机读文件**：`tests/unit/evaluation/fixtures/eval_fixtures_v1.json`（产品经理提供），包含每个夹具的完整输入（逐日开高低收）与期望值。本文档是它的可读版本，两者内容一致；若发现不一致，以 JSON 为准，并报告产品经理。
- **期望值的来历**：由产品经理按 17 号与 T09 卡第 3 节的实现决定，用一份与项目代码独立的参照实现逐日计算，并对关键夹具手工复核。实现者不得修改期望值；实现结果与期望值不一致时，按 `docs/tasks/README.md` 停止并报告，写明日序号、字段、期望值与实现值。
- **通用约定**：
  - **日序号**：合成交易日历，自 2011-01-03（周一）起的连续工作日（周一至周五，不含节假日）；第 i 日即第 i 个工作日，i 从 0 起。所有夹具的日期都早于 2020 年。
  - **日线**：每日给出开、高、低、收（六位小数），原始价与复权价相同；`null` 表示缺价日（日历上有这一天，但没有日线）。
  - **参数**：G = 10；公共可评估掩码为"当日有日线，且本历史段的有效日线计数（含当日）≥ 83"。事件参数为 ρ\_end = 0.5、W\_Q = 20、上限 252、安静 10 日、确认 20 日；E\_pct 的 T 与 E\_atr 的 X 见各夹具。S2 等窗口参数为 ρ = 0.5、Y\_cap = 60、Y\_max = 252、n\_min = 10。
  - **数据终点**：序列的最后一日，终止原因 DATA\_END。右端截尾记为 `RIGHT_DATA_END`。
  - **比率**：十进制 12 位小数（ROUND\_HALF\_EVEN）。表中省略末尾的 0，例如 0.5 即 0.500000000000。
  - **方法的逐日状态**：以区段给出，格式为 [起日, 止日（含）] episode\_id 起始等级（某日起改为某等级）；区段之外的日子不在警。
- **事件字段**：s 开始日；p 峰值日；C\_p 峰值收盘；e 结束日；原因 a / b / c；确认日；标记（cap：以 (c) 结束；peak\_in\_confirm：确认期内回到峰值；confirm\_cut\_by\_cap：确认期在上限处截止）；报告谷底；k\*（右端截尾时的暂定谷底）；截尾（RIGHT\_<原因>、MISSING 缺价、DATA\_BREAK 历史断点）；不可评估（WARMUP 预热、MISSING 缺价）；依赖未决（(e, 数据终点] 及其中的有效日数）；标签可确定日；上限延续；并入次数；是否进入主口径。
