## 2. 分层规则

与 Spring Boot 的对应关系，便于理解：

| 层 | 对应 | 职责 | 允许依赖 |
| --- | --- | --- | --- |
| `interfaces` | Controller | 解析命令或请求，调用用例，输出结果 | bootstrap、application、config |
| `bootstrap` | `@Configuration` | 唯一组装依赖的地方 | 全部 |
| `infrastructure` | Repository 实现 / 外部客户端 | 实现 application 定义的端口 | application（端口与模型）、domain |
| `application` | Service | 用例编排；在 `ports.py` 定义所需的端口 | domain |
| `domain` | 实体 / 领域服务 | 指标、生命周期状态机、封存策略等纯规则 | 只能依赖标准库 |
| `config` | `application.yml` | 读取 .env 与环境变量 | 标准库 |

由 `lint-imports` 强制执行，契约写在 `pyproject.toml`。违反契约的代码不得合入。除分层契约外，另有两条 forbidden 契约：domain 不依赖 config 与任何 I/O 层；interfaces 不得直接导入 infrastructure 与 domain，需要的读取（如下载清单）经 bootstrap 提供（Gemini 第二阶段 B-01）。

**最重要的一条：算法（指标、生命周期、证据判定）全部放在 domain，不碰文件、网络、数据库和时钟。** 这样同一套规则可以被回放、单元测试和每日计算原样复用，也能逐条对照规格做验收。

## 3. 编码规范

1. Python 3.13，使用 uv 管理环境；运行时依赖尽量少，新增依赖要在变更记录里说明理由。
2. 全部函数写类型标注；领域对象用 `@dataclass(frozen=True, slots=True)`。
3. 一个模块只做一件事。文件超过约 300 行、函数超过约 50 行时，先拆分再继续写。
4. 禁止在业务代码里 `print`；输出走 interfaces 层或注入的回调。
5. 不吞异常：数据源调用失败抛 `PriceSourceError`，封存越界抛 `SealViolation`，并且立即停止。
6. 密钥只在 `config/settings.py` 读取，类型为 `Secret`（T08a D-05）：`repr`、`str`、格式化、`dataclasses.asdict` 的副本都只显示 `***`，json 不能直接序列化（以 `default=str` 序列化时写出 `***`），不能 pickle；取值必须显式调用 `reveal()`。不写入日志、文件或异常信息。
7. 每个 domain 规则都要有单元测试；规格里的验收夹具（S、F 系列）逐条写成测试，测试名带夹具编号。

## 4. 常用命令

```
uv sync                       安装依赖（含 dev 组）
uv run pytest                 运行测试
uv run pytest tests/unit/evaluation   评价模块夹具与属性
uv run lint-imports           检查分层契约
uv run ruff check .           代码检查
uv run ruff format .          格式化
uv run stock-risk fetch-raw   下载探索期原始数据
uv run stock-risk audit-raw   审计原始数据（只报告；有阻断问题时退出码为 1）
uv run stock-risk check-calendar   用 XNYS 独立日历核对 SPY 日历代理（I13）
uv run stock-risk show-ranges      各代码三个区间、端点类型与缺价日（I2、I3）
uv run stock-risk replay --candidates reference12   12 组参考候选回放、四种输出与汇总
uv run stock-risk replay --candidates all           768 组全量汇总（多进程）
uv run stock-risk compare                           v0.8 对照回放与时间线（T06b、T06c）
uv run stock-risk probe-tickers                     选参集代码清单探查（一个请求，不下载价格；T08d-1）
uv run stock-risk fetch-batch --list L              选参集批量下载（额度保护、断点续传；T08d-1）
uv run stock-risk probe-massive                     Massive 数据源试验（历史日期清单与已知案例，不下载价格；T08d-2a）
uv run stock-risk probe-massive --followup          Massive 追加探查（去掉类型、交易所过滤，补充案例，与 Tiingo 对照；T08d-2a 第 2.4 节）
uv run stock-risk regress-v0 --baseline <run_id>    V0 真实数据回归（T06a）
```
