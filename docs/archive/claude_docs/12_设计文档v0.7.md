## 1. 预警生命周期规格

每只股票同一时间最多一次进行中的预警。启动时冻结基准；每天先用昨日状态和今日价格判断等级转移，再用转移后的字段计算恢复进度与事件。所有比较按 v0.4 第 2.0 节的数值规范（ε\_r、ε\_p）。

### 1.1 状态与字段

| 显示状态 | 含义 |
| --- | --- |
| 正常 | 无进行中的预警，历史段充足 |
| 关注 / 警戒 | 预警进行中 |
| 数据中断 | 连续缺价达到历史断点后，直到数据恢复；不等于正常或解除 |
| 不可计算 | 当前历史段有效日线不足 W + N 条 |

**证券级字段**：当前历史段起点 seg\_start；连续缺价天数 m；当前历史段内最近一次解除日 last\_release（历史断点时清空）。

**预警字段**（episode\_id 下）：

| 字段 | 含义 | 更新 |
| --- | --- | --- |
| P\_ep、p\_ep、ATR\_ep | 冻结基准 | 只在启动时写入 |
| L\_ep、l\_ep | 本次低点（p\_ep 以来最低收盘） | 启动、今日新低 |
| obs\_start、cycle\_no | 稳定观察起点与周期序号 | 见第 1.2 节“观察重置” |
| box\_high | 冻结企稳区间最高收盘（仅 BOX） | 本周期首次企稳日写入；观察重置时清空 |
| downgraded | 本次预警是否曾由警戒降为关注 | 首次降级时置是，之后不再改变 |
| H\_d | 本段“关注（降级而来）”以来最高收盘 | 每次降级时 H\_d = 当日收盘；仅当前为关注且 downgraded = 是时取 max(H\_d, C)；加重时清空（G-04） |
| dc、rc、xc | 降级、解除、强恢复计数 | 第 1.4 节 |
| obs\_issued | 本周期是否发出过 RECOVERY\_OBS | 观察重置时清空 |
| prev\_confirm | 上一有效交易日恢复确认是否成立 | 每个有效交易日末尾写入 |

### 1.2 每日处理流程（G-01、02、03、06）

**A. 数据**

1. 当日缺价：m 加一。
   - m ≤ G：有预警时等级与字段冻结，三计数清零，执行“观察重置”；若 prev\_confirm 为真，当日发 RECOVERY\_REVOKED（DATA\_GAP）；发 DATA\_ISSUE。结束。
   - m = G + 1：历史断点确认。有预警时以 DATA\_BREAK 结束并清空预警字段；清空 last\_release；显示“数据中断”；发 DATA\_ISSUE。结束。
   - m > G + 1：保持“数据中断”，不再产生事件。结束。
2. 当日有日线：若此前 m ≥ G + 1，以今日为新历史段起点 seg\_start。m = 0。
3. 当前历史段有效日线不足 W + N 条 → 显示“不可计算”，结束。

**B. 无预警：只算启动证据**

4. 计算受限回撤 D\_T 与 R2（第 1.3 节）。不满足启动 → 正常，结束。
5. 启动：新 episode\_id；P\_ep、p\_ep 取受限窗口最高收盘及其日期（并列取最近）；ATR\_ep = 启动当日计算 D\_T 所用的分母 A\_start；L\_ep、l\_ep = \[p\_ep, T\] 最低收盘及其日期（并列取最早）；obs\_start = T，cycle\_no = 1；其余字段清空；初始等级 = D\_T ≥ k₂ 时警戒，否则关注。发 START。结束（启动日不判断降级、解除或恢复进度）。

**C. 有预警**

6. **转移证据**（用昨日字段与今日收盘）：今日新低 = C < L\_ep − ε\_p；D\_ep；若当前为关注且 downgraded：H\_d = max(H\_d, C)，回吐比率 = (H\_d − C) / ATR\_ep。
7. **新低**：更新 L\_ep、l\_ep；执行观察重置。
8. **加重**（仅关注时）：未降级过且 D\_ep ≥ k₂；或已降级过且（今日新低或回吐比率 ≥ k₁）。命中则升为警戒，发 ESCALATE，执行观察重置，三计数清零，H\_d 清空，跳到第 11 步。未命中继续第 9 步。
9. **观察证据**（用第 7 步之后的字段）：since\_obs、企稳、长期稳定、恢复确认、U、强恢复、E\_down、E\_rel（第 1.3 节）。今日新低时，企稳、确认、强恢复、E\_down、E\_rel 一律为假或空。
10. **计数与降级、解除**（第 1.4 节）。
11. **恢复进度事件**（第 1.5 节），然后写入 prev\_confirm。
12. 观察标签（v0.4 第 2.6 节，只改文案）。

**观察重置**（G-03）：obs\_start = T；box\_high、obs\_issued 清空；三计数清零；cycle\_no 在上一交易日的值上加一。**同一交易日内，无论由新低、加重、缺价中的几项触发，只执行一次，cycle\_no 至多加一。**

### 1.3 定义

| 名称 | 定义 |
| --- | --- |
| 受限窗口（G-11） | 当前历史段内含 T 的最近 W 条有效日线；若 last\_release 存在，只取 last\_release 当日及之后的日线 |
| A\_start（启动分母） | 候选维度 atr\_basis：PEAK 时 = ATR\_N(P^max 日)；MIN 时 = min(ATR\_N(P^max 日), ATR\_N(T))（G-09） |
| 受限回撤 D\_T | (P^max − C) / A\_start，P^max 为受限窗口最高收盘 |
| 启动条件 | D\_T ≥ k₁，或 R2 触发（v0.4 第 2.3 节，g 固定） |
| D\_ep | (P\_ep − C) / ATR\_ep；启动当日 D\_ep = D\_T |
| since\_obs | obs\_start 之后到 T 的有效交易日数（obs\_start 当日为 0） |
| 企稳 / 长期稳定 | since\_obs ≥ K / since\_obs ≥ K\_stab |
| 恢复确认（候选维度 confirm） | SMA：企稳且 C > SMA10(T) + ε\_p。BOX：since\_obs > K 且 C > box\_high + ε\_p，box\_high = obs\_start 后第 1 至第 K 个有效交易日的最高收盘，在第 K 天冻结。BOX\_ROLL：since\_obs > K 且 C > 今日之前最近 K 个有效交易日的最高收盘 + ε\_p（G-08） |
| U | (C − L\_ep) / ATR\_ep（L\_ep 为第 7 步后的值） |
| 强恢复（G-05） | 恢复确认成立，且 C − L\_ep ≥ min(u\_rel × ATR\_ep, φ × (P\_ep − L\_ep))；φ = 0.5【待批准】。等价于“反弹达 u\_rel 个 ATR，或已收复本次跌幅的 φ” |
| E\_down（警戒时） | a：D\_ep < k₂；b：恢复确认；c：长期稳定 |
| E\_rel（关注时） | a′：D\_ep < k₁；b′：强恢复。长期稳定不能解除 |

**强恢复修订的边界**：该修订解决“浅跌后已收复大半、却既不接近原高点又达不到 u\_rel 反弹”的长期挂警报。价格长期停在本次跌幅一半以下时，关注仍会保留，这是设计意图，由评价中的“长期未解除”门槛约束。

### 1.4 计数规则（G-10）

| 计数 | 累计 | 清零 |
| --- | --- | --- |
| dc | 警戒时 E\_down 非空加一 | E\_down 为空；任何等级变化；观察重置 |
| rc | 关注时 E\_rel 非空加一 | E\_rel 为空；任何等级变化；观察重置 |
| xc（仅 release\_path = DIRECT） | 警戒或关注时强恢复成立加一 | 强恢复不成立；启动、加重、解除；观察重置。**由警戒降为关注时不清零** |

- 原因交替：只要当日证据集合非空，计数连续累计，不要求同一项；转移时记录计数段内每日的证据集合。
- 警戒时优先级：xc 达到 d → 解除（DIRECT\_STRONG\_RECOVERY）；否则 dc 达到 d → 降为关注，downgraded = 是，H\_d = C。
- 关注时：xc 或 rc 达到 d → 解除（记录当日成立的证据）。
- 每天最多一次等级变化。
- 解除：预警结束，last\_release = T，记录解除收盘；当日不再判断启动。

### 1.5 恢复进度事件（G-02、F4）

按顺序判断，当日解除时不发以下任何事件：

| 情形 | 事件 |
| --- | --- |
| 今日新低，且被终止的周期 obs\_issued 为真 | RECOVERY\_FAIL（NEW\_LOW）。本周期从未发出恢复观察时不发恢复失败 |
| 非新低的加重导致观察重置，且 prev\_confirm 为真 | RECOVERY\_REVOKED（ESCALATED） |
| 无观察重置：本周期首次企稳 | STABILIZED |
| 无观察重置：恢复确认由假变真 | RECOVERY\_OBS（本周期第 n 次）；obs\_issued = 真 |
| 无观察重置：恢复确认由真变假 | RECOVERY\_REVOKED（BELOW\_SMA 或 BACK\_INTO\_BOX） |
| 缺价日且 prev\_confirm 为真 | RECOVERY\_REVOKED（DATA\_GAP），在缺价当日发出 |

业务身份沿用 v0.6 第 1.7 节；RECOVERY\_REVOKED（ESCALATED）的身份为 (episode\_id, 被终止的 cycle\_no, 对应的第 n 次)。通知文案只陈述事实，不用“底部确认”，不给操作或仓位建议。

### 1.6 状态修正与衔接（G-07、G-17）

沿用 v0.6 第 1.8 节，修订三处：

- **比较对象只含离散字段**：显示状态（含等级）、是否存在进行中预警、恢复进度（无 / 企稳 / 恢复确认）。复权缩放导致的 P\_ep、L\_ep 等价格字段等比例变化不触发 STATE\_CORRECTION。
- **STATE\_BRIDGE 只在 P+1 至 T−1 间至少有一个生命周期事件时发送**；没有事件则不发。
- **状态快照**（P 日投递 FAILED、UNKNOWN，或从未发布）以 T 日计算完成后的状态为准，包含当日事件及依据；当日不再另发增量事件。

## 3. 理论最短等待（G-12）

**前提**：起点日 t 为最近一次观察重置日（新低、加重或缺价）或启动日；此后每个有效交易日恢复确认一旦可以成立就成立，强恢复也同时成立；不经由 a、a′、c。下表是**下限**，实际等待还受均线或区间滞后、反弹幅度、撤销与缺价影响。

**推导**（e 为确认方法的最早偏移：SMA e = 0，BOX 与 BOX\_ROLL e = 1）

- 恢复观察最早：t + K + e。
- 从警戒起，两段解除：dc 自 t + K + e 起累计 d 天降级，次日起 rc 累计 d 天 → t + K + e + 2d − 1。
- 从警戒起，直接解除：xc 自强恢复首日起连续累计 d 天，中途降级不清零（G-10） → t + K + e + d − 1。
- 从关注起（未降级过的关注创新低但未加重，或关注启动）：只有 rc（或 xc）一段 → t + K + e + d − 1，两种解除路径相同。

**表：自起点日 t 起的有效交易日数（下限）**

| K | d | 恢复观察 SMA | 恢复观察 BOX / ROLL | 警戒起两段 SMA | 警戒起两段 BOX / ROLL | 警戒起直接 SMA | 警戒起直接 BOX / ROLL | 关注起 SMA | 关注起 BOX / ROLL |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| 3 | 3 | 3 | 4 | 8 | 9 | 5 | 6 | 5 | 6 |
| 3 | 5 | 3 | 4 | 12 | 13 | 7 | 8 | 7 | 8 |
| 5 | 3 | 5 | 6 | 10 | 11 | 7 | 8 | 7 | 8 |
| 5 | 5 | 5 | 6 | 14 | 15 | 9 | 10 | 9 | 10 |

**补充**

- 强恢复若比恢复确认晚 j 天才成立，直接解除顺延 j 天（G-10 修订后不再跳变为两段时间）；但若 dc 先达到 d，状态会先降为关注，不影响解除日。
- 价格回到 k₂ 以内（a）可使降级早于企稳；接近原高点（a′）可使解除不依赖恢复确认。浅跌时实际等待可能短于上表。
- 长期稳定（c）可使降级在 t + K\_stab + d − 1 发生，但不能解除。

| release\_path（解除路径） | {TWO\_STAGE, DIRECT} | 结构 |
| atr\_basis（启动分母） | {PEAK, MIN} | 结构 |

2⁶ × 3 × 2 × 2 = 768。网格序号按上表自上而下的字典序编号 1–768。

**新增的两个维度**

- **BOX\_ROLL**（G-08）：针对冻结区间在企稳期内出现单日冲高后长期无法确认（F2）。它可能带来更多撤销与重新确认（见 F4 误触发）。冻结区间 BOX 是发起人已同意的候选，保留不替换。
- **atr\_basis = MIN**（G-09）：针对峰值日 ATR 虚高（财报巨震、高位放量）后低波阴跌时预警过晚甚至漏报，这对发起人关注的成长股尤其重要。代价是低波动时的小幅下跌也可能启动（F 负担增加）；另外 ATR\_ep 较小使解除所需的 a′ 更接近原高点。MIN 与 PEAK 的取舍由评价决定。

**不删减的理由与代价**：计算成本可以忽略；在看结果前删减需要额外理由而我们没有。候选从 256 增加到 768，选参的乐观偏差也随之增大：所选候选的开发期表现会高估其真实表现。这一点只能靠门槛、稳健性要求、冻结后只跑一次的验证期，以及报告全部 768 组结果来约束。

### 5.4 覆盖与归属

- **覆盖**（多对多）：预警在事件 \[峰值日, 谷底日) 内任一天进行中。
- **预警归属**（唯一）：START 信号日落在某事件 \[峰值日, 谷底日) 内则归属该事件（多个取峰值日最早者）；早于其覆盖的所有事件则归属最早覆盖的事件，标“继承”。
- **解除归属**：每次 RELEASE 归属其所在预警；只在其后的 Q 与 Q\_L 窗口内评价，窗口之后的新下跌不追溯到这次解除。
- 两套事件集分别独立建立。

### 5.5 事件结果与得分（共同事件全集）

| 类别 | 判定 |
| --- | --- |
| 新通知 | 信号日落在 \[峰值日, 谷底日) 内的第一个 START，或升至警戒的 ESCALATE |
| 继承覆盖 | 区间内没有新通知，但峰值日已有进行中的预警 |
| 未提醒 | 区间内没有新通知，峰值日也没有进行中的预警 |
| 截尾 | 事件无法确认 |

- **S1 新通知及时性**（\[0, 1\]，越小越好）：新通知信号日已实现跌幅 ÷ 事件最大跌幅；继承覆盖、未提醒记 1。**另分开报告**：新通知为 START 与为 ESCALATE（来自峰值日前已存在的预警）的占比与各自 S1（G-14）。
- **S2 恢复后预警滞留**（交易日，越小越好）：从 R\_E 起处于进行中预警的交易日数，上限 Y\_cap；未恢复事件不计。
- **谷底日预警在场率**（只报告，G-13）：谷底日处于进行中预警的事件占比。

S1 只衡量通知是否及时；解除是否过早由第 5.8 节衡量。不把“谷底前解除”折算进 S1，以免两类错误混在一个得分里，也与 J-17 一致。

### 5.6 恢复参考点与回升口径

- R\_E：谷底日之后，首个收盘 ≥ 谷底 + ρ ×（峰值收盘 − 谷底）的交易日。**搜索范围至 min(谷底 + Y\_max, 同一证券同一事件集下一事件峰值日前一日)**；范围内找不到则记“未恢复”（G-15）。ρ、Y\_max【待批准】。
- 每个 RECOVERY\_OBS、RELEASE 报告：距谷底交易日数、回升占比、距低点涨幅。Y 等及时性要求由发起人据此登记。

### 5.7 恢复观察的评价

每个 RECOVERY\_OBS 之后固定 Q 个交易日：是否发生 RECOVERY\_FAIL、是否出现第 5.8 节的严重不利变化；每次预警内恢复观察的反复次数。只报告。

### 5.8 解除后的不利变化（G-13）

每个 RELEASE（日 r，收盘 C\_r）之后两个固定窗口 Q、Q\_L（Q\_L > Q）【待批准】。严重不利变化：窗口内任一日收盘 ① 较 C\_r 下跌 ≥ y\_pct；② 较 C\_r 下跌 ≥ y\_atr × A\_r（A\_r 为 E\_atr 度量的 ATR₂₀(r)）；③ 跌破所解除预警的 L\_ep。两个窗口分别报告；“解除发生在归属事件谷底之前”的占比只报告。

### 5.10 确认性比较

只在 E\_pct 上做两项：候选对冻结基线的 S1 与 S2 改进（改进量 = 基线均值 − 候选均值）。理由是减少与 ATR 算法同型的评价偏向，并不宣称百分比事件天然公正。配对单位为同一事件，全集包括所有类别。单侧，原假设改进量 ≤ 0；Holm 校正，α = 0.05。
