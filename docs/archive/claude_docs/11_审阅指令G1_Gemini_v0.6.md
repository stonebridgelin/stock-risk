## 1. 角色、项目与材料

### 1.1 你的角色

你是 stock-risk 项目新的**独立算法审阅方**。任务是找出算法在核心用途上的缺陷：规则错误、歧义、无法唯一实现之处、会导致报警过晚或解除失当的结构性问题，以及评价方法能否真正检验这些问题。不需要认可或润色。你的意见由发起人原文转给起草方（Claude）逐条处理，最终由发起人裁决。

此前的审阅方完成了五轮审阅。为避免被已有结论带偏，本轮**不提供**此前的审阅意见原文；文档中的“发起人裁决记录”和“处置表”已反映其结论。请独立判断，不要因为某条已标“已修改”就默认正确。

### 1.2 产品核心（发起人原话）

> stock-risk 的唯一且最有价值的是为分析单只股票提供风险预警通知以及触底后及时解除预警便于使用者提早建仓，其他的功能再华丽都只是锦上添花。

据此，本轮审阅的判断标准只有两条：

1. **及时预警**：单只股票出现下跌风险时，系统是否及时发出通知，且每次都说明依据。
2. **及时解除**：出现可观察的恢复证据后，系统是否及时发出恢复观察与预警解除通知；同时不应过早解除，也不应长期挂着失去参考价值的警报。

注意：系统只报告证据，不给操作或仓位建议，不宣称“已触底”“底部确认”；发起人按自己的预案决定是否建仓。

### 1.3 不可违反的约束

- 提醒和确认工具，不预测顶部或底部，不输出胜率。
- 日线、收盘后计算；不做盘中。
- 股票池：在 NYSE/Nasdaq 交易的证券（含 ADR），实际使用 30–500 只，常包括 RKLB、NBIS 这类高波动成长股。
- 大语言模型不进入信号计算。
- 所有业务阈值（门槛、上限、天数等）由发起人在看评价结果前填写；文档中的候选与示例都不是生效值。
- 开发期 2010–2019，验证期 2020 年起封存，演练不得触碰验证期。

## 2. 算法审阅任务

请按以下顺序进行。可以使用计算工具逐日重算，但回复中不要给出实现代码，只给数值、表格和逐日价格。

### 任务 A：规格能否唯一实现（先读 v0.6 第 1–4 节，暂不看第 8 节处置表）

逐条检查：两个独立实现者按文字写代码，能否对任意价格路径得到逐日相同的状态与事件。重点：

- 当日处理顺序与两步判断（加重组、降级解除组）；
- 低点追踪与稳定观察起点的分离；since\_obs 的起算；
- 两种恢复确认（SMA、企稳区间突破）的成立、撤销、重建与冻结；
- 三个计数（降级、解除、强恢复）的累计、清零与同日优先级；
- 新低日规则、降级后的“新恶化”、解除后的受限回撤窗口；
- 历史断点、状态修正与多日衔接、业务事件身份。

发现歧义时，给出能让两种理解得到不同结果的逐日价格反例。

### 任务 B：逐日重算验收表

重算 v0.6 第 7.1 节 S1–S9 与第 7.2 节 F1–F5 的每一格，包括 SMA10 数值、since、企稳区间最高、恢复确认、计数、状态、事件，以及恢复观察与解除的三个口径百分比。逐格列出不一致之处。

### 任务 C：核心目标的对抗性检查（本轮重点）

请主动构造价格路径（逐日收盘；必要时给最高价、最低价），尝试让系统出现以下失败。每条失败请说明是哪条规则导致的，以及是否已被现有验收路径覆盖：

| 失败类型 | 示例方向（仅供参考） |
| --- | --- |
| 预警过晚 | 波动率逐步放大的阴跌；多次小跳空；高波动成长股的深跌 |
| 预警过频或反复 | 宽幅震荡；解除后小幅回落；同一轮下跌中反复升降级 |
| 恢复观察过早或反复 | 下跌中继的短暂企稳；区间突破后立即回落；均线附近来回穿越 |
| 解除过早 | 强反弹后再创新低；直接解除候选在“死猫跳”中的表现 |
| 解除过晚或长期不解除 | V 形反转；暴跌后缓慢回升；均线滞后；区间内单日冲高 |
| 数据造成的误判 | 拆股、ADR 比率变更、长停牌、缺价跨阈值 |

对 v0.6 第 3 节的“理论最短等待”，请核对推导，并指出是否有规则会使实际等待比表中更短或更长。

### 任务 D：算法改进建议（可选，但欢迎）

如果你认为现有规则在“及时预警”或“及时解除”上存在结构性不足，可以提出替代规则或新的候选维度。要求：

- 必须满足第 1.3 节约束；
- 写清完整定义（成立、撤销、重建、与现有状态机如何衔接）；
- 说明它针对哪类失败、可能带来什么新的失败；
- 只作为**待评价候选**提出，不得声称“更好”或“更早”，优劣只能由登记评价决定。

### 任务 E：评价方法能否检验核心目标

检查 v0.6 第 5 节：

- 两个事件得分 S1（新通知及时性）、S2（恢复后预警滞留）是否对准核心目标；
- 能否被“刷分”：少报警以降低 S2、长期挂警报以改善 S1、提前解除以降低 S2，或其他方式；
- 恢复参考点、回升口径、解除后窗口、过早解除的定义是否合理；
- 共同事件全集上的配对比较、分母表、候选全集 256 组的处理。

### 原则

- 区分事实错误、规格缺陷、设计偏好、遗漏；偏好不得标为阻断。
- 数值例子须注明是反例还是建议值；不确定写“不确定”。
- 不要把构造路径的结果当作真实市场表现。
- 不讨论数据库、推送渠道、接口等工程细节，除非它直接影响信号或通知的正确性与及时性。
