你仍是独立审阅方。本轮审阅《stock-risk 设计文档 v0.5：预警生命周期与逐日验收表》（发起人以导出文件附上）。v0.5 只替换 v0.4 的规则核心与评价协议，替换关系见其第 0.1 节；其余沿用 v0.4。**本轮不视为批准公式或开发；R3 各条须依据 v0.5 的实际规则与验收结果逐条关闭。**

## 2. 审阅任务

1. **规则可实现性（盲审，先不看第 6 节）**：按第 1 节规格与第 2 节转移表，判断两个独立实现者能否得到逐日相同的状态与事件。重点：
   - 当日证据与优先级；
   - 原因交替计数；
   - 新低日规则；
   - 降级后的“新恶化”；
   - 解除后的受限窗口；
   - 启动时 D\_T 与 D\_ep 的一致性；
   - 状态修正。
2. **逐日表核算**：按规则逐日重算第 3 节 P1–P9 与 P10 组合表，指出任何一格与规则推导不一致之处。
3. **两个阻断**：判断 P8、P9 及 T8–T10、T18–T19 是否足以证明：没有新恶化不会反复升降级，旧跌幅不会造成反复解除与启动，同时不屏蔽真正的新下跌。如认为路径不足，请给出能暴露问题的反例路径（逐日价格）。
4. **核心目标的覆盖**：生命周期规则本身是否存在报警过晚、解除过早、长期不解除的结构性风险（可用反例路径说明）。
5. **评价协议**（第 4 节）：两套事件集、关联规则、恢复参考点与结果类别、过早解除与严重不利变化、F 口径、保守口径、基线、单阶段选参、检验、重采样、最小样本。检验标准：能否唯一实现，是否对准核心目标。
6. **R3 复核**：对第 6 节逐条给出“可关闭 / 部分解决 / 未解决”。

原则不变：区分事实错误、规格缺陷、设计偏好、遗漏、回归；偏好不得标为阻断；数值例子请标明是反例还是建议值。
